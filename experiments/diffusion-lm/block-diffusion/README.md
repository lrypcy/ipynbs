# block-diffusion：块扩散的两笔账（可表达性与算力）

对应文章：[扩散语言模型（02）：块扩散——同时解几个 token，就丢掉多少互信息](https://lrypcy.github.io/2026/11/02/diffusion-lm-02-block-diffusion/)

## 要验证的论断

| 组 | 论断 |
| --- | --- |
| A | 完美模型下，块扩散能表示的最优分布族仍然装不下真实分布；KL 下界**等于**同组 token 之间的条件 total correlation，逐位相等 |
| B | 损失的不是「同时解几个」，而是「同时解的那几个之间有没有相关性」：相邻配对 KL=0，间隔配对 KL=1.598 |
| C | 两端对齐：B=1 精确等于自回归（KL=1e-17），s=L 精确等于「所有位置独立」（KL=3.195） |
| D | KV 缓存逐块复用与全量重算逐位一致（2.2e-16）；改成「只看本块」立刻差 1.726 |
| E | 固定调用次数下，块扩散的 attention 成本是全序列扩散的 $$B(L+B)/2L^2$$，数值比与闭式逐位相等 |

## 运行

```bash
python block_diff_lab.py            # A–E 全部，约 0.3 秒
python block_diff_lab.py A B        # 只跑指定组
```

环境：**纯 numpy**，不需要 GPU。固定种子 `20261105`，全部通过才输出 **断言总数 = 21**。

### 为什么是 V=4、L=6

$$4^6=4096$$ 条序列可以全部枚举，于是「真实分布」是一个精确的数组，而不是采样估计：
每一条关于 KL、熵、total correlation 的断言都能算到 1e-15，不掺采样噪声。
数据用二阶马尔可夫链 $$\Pr(x_i=x_{i-2})=0.85$$——耦合落在**距离 2** 上，
这样「相邻配对」与「间隔配对」会给出完全不同的结论，正好把机制暴露出来。

### 三处不能省的细节

1. **条件分布广播要按轴位置对齐，不能靠 numpy 右对齐**。`p(x_pre, x_i) / p(x_pre)` 里
   `p(x_pre)` 的形状是 `(V,)*len(pre)`，直接除会被右对齐到 `(x1..x4)` 这种错位轴上。
   实测症状：`sum(q)=33.4`、KL 变成负数（−1.6999）。改成「把瘦数组按轴位置放回全秩形状」才对。
2. **同组 token 必须各自独立地从逐位置边缘采**。写成 `p(x_{G} | x_{<G})`（组内保留联合）
   会让 s=L 时 `q*=p`、KL=0——把「一次并解」错误地当成了「一次联合采样」。
   块扩散的真实结构是 $$\prod_{j}\prod_{i\in G_j} p(x_i\mid x_{<G_j})$$。
3. **「下界最优」要在族内扰动**。掺均匀分布会把 $$q^*$$ 推出这个族，KL 反而下降（1.0912→1.0831）；
   正确做法是把条件分布做温度缩放（仍在族内），KL 才单调变差。

族内温度缩放（B=3, s=3，$$q^*$$ 处 KL=1.0912）：T=0.70→1.3005、0.85→1.1322、1.15→1.1178、1.40→1.2294。

### B：损失来自「相关性」，不来自「并行度」

- 组大小 s=1：B∈{1,2,3,6} 的 KL 都是 1.02e-17 —— **块大小本身不花表达力**。
- 块内 s 从 1 到 6：KL = 0 / 0 / 1.0912 / 3.1952。s=1→2 一点没损失，因为距离 2 的耦合被完整地留在了跨组条件里。
- 组大小都是 2、只换配对（B=4）：相邻 (1,2)(3,4) = 0.000，间隔 (1,3)(2,4) = **1.598**，交错 (1,4)(2,3) = 0.000。

### C：两端对齐

- B=1：KL = 1.02e-17，$$\sum p\log q^*=-5.122592=-H(p)$$，即 $$q^*=p$$。
- s=L：$$q^*$$ 恰好等于六个边缘的乘积（最大差 0.00e+00），KL = 3.195 —— 这是本数据上并行解码的天花板。

## 四条结论

1. **可表达性有闭式下界**：$$\mathrm{KL}(p\|q^*)=\sum_j \mathrm{TC}\big(p_{G_j\mid x_{<G_j}}\big)$$，数值对到 1e-14。
   即使模型完美，块扩散也只能逼近到这个距离。
2. **代价由「耦合」而非「并行度」决定**：块大小从 1 变到 6、组大小恒为 1 时 KL 一动不动（1.02e-17）；
   把强耦合的两个位置塞进同一组，KL 立刻从 0 跳到 1.598。
3. **两端是同一个公式的退化**：B=1 给出自回归（KL=0），s=L 给出独立假设（KL=总相关 3.195）。
   块扩散在这条谱上只是一个中间点。
4. **算力省在 query 数上，不省在 cache 上**：固定调用次数时成本比恰好是 $$B(L+B)/2L^2$$；
   cache 的作用是把「前缀重算」那一项抹掉（B=8 时 0.781% → 0.394%）。自回归仍然最省。
