# elbo_masked_diffusion：掩码扩散 ELBO 的数值验证

对应文章：[扩散语言模型（01）：离散扩散的 ELBO](https://lrypcy.github.io/2026/10/12/diffusion-lm-01-discrete-diffusion-elbo/)

## 要验证的论断

1. 吸收态前向核 / 反向核的转移概率就是 $$(\alpha_s-\alpha_t)/\alpha_s$$ 与 $$(\alpha_s-\alpha_t)/(1-\alpha_t)$$（在 $$\alpha_t = 1-t$$ 下等于 $$(t-s)/(1-s)$$ 与 $$(t-s)/t$$）。
2. 掩码率必须随机（$$t\sim\mathcal{U}[0,1]$$）；固定 15% 训练出来的模型在高掩码率处没有学习信号，因而无法从全 `[MASK]` 生成。
3. 带 $$1/t$$ 权重的训练损失是 $$-\mathbb{E}[\log p_\theta(x_0)]$$ 的**上界**；去掉 $$1/t$$ 后不再是同一个量（数值上会掉到 NLL 之下）。
4. $$1/t$$ 的作用是量纲归一（把"按被掩码 token 求和"拉回"每 token 均值"），代价是抬高估计方差。

## 运行

```bash
python run.py        # 纯 numpy，CPU，约 15 秒；结果写入 results/summary.md
```

环境：python 3 + numpy（miniconda base 即可），固定种子 `20261012`。

## 结果（`results/summary.md`，本机实跑）

| 项 | 数值 |
|---|---|
| 前向 $$\mathrm{P}(\text{mask}@t \mid \text{unmask}@s)$$ | 经验 0.57067 vs 理论 0.57143（偏差 7.6e-4） |
| 反向 $$\mathrm{P}(\text{unmask}@s \mid \text{mask}@t)$$ | 经验 0.57129 vs 理论 0.57143（偏差 1.4e-4） |
| 固定 15%：全掩码上下文被观测次数 | **0 次 / 200000** |
| 均匀 $$t$$：全掩码上下文被观测次数 | 28399 次 / 200000 |
| 固定 15% @ t=1 的 CE | 1.3863 = $$\ln 4$$（退化成均匀分布） |
| 均匀 $$t$$ @ t=1 的 CE | 1.2929 |
| 生成序列超出熵的量 | 固定 15% +1.2219，均匀 $$t$$ +0.5256（**2.33 倍**） |
| $$-\mathbb{E}[\log p_\theta(x_0)]$$ | 3.6602 |
| 带 $$1/t$$ 的损失 | 3.6602（差 +0.0000，是上界） |
| 去掉 $$1/t$$ 的损失 | 1.9220（差 −1.7382，**不是上界**） |
| 蒙特卡洛估计方差（n=16） | 带 $$1/t$$ 2.5021，不带 0.1608（比值 15.6） |

## 结论

- A 组确认前向核 / 反向核的表达式，两个分母（$$\alpha_s$$ 与 $$1-\alpha_t$$）不能写错。
- B 组给出"固定掩码率为什么不够"的机制证据：长序列下全掩码上下文的出现概率是 $$0.15^L$$，训练中一次都见不到，模型只能回退到均匀分布；换成随机掩码率后同一上下文被观测近 3 万次，生成质量立刻接近真实分布。
- C 组是最关键的一条：用**真实后验收敛器**时，带 $$1/t$$ 的损失与 NLL 精确相等（变分间隙为 0），去掉 $$1/t$$ 后掉到 NLL 之下——说明这个权重不是可调的"技巧"，而是让损失成为 NLL 上界的必要条件。
- D 组说明 $$1/t$$ 会把高掩码率区间的贡献从 45.9% 压到 27.5%（更均衡），代价是估计方差上升约一个数量级；实践中靠大批次与更多训练样本摊掉。
