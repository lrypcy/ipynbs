# dit_core：DiT 核心机制的数值验证

对应文章：[《扩散 Transformer（01）》](https://lrypcy.github.io/)（`lrypcy.github.io` 生成模型分类，DiT 系列第 1 篇）。

## 这份脚本回答什么

关于 DiT 的很多说法停留在「人人都这么说」的层面：patch size 很关键、AdaLN-Zero 让训练更稳、
时间步不能丢、交叉注意力比全局向量更能做属性绑定、步数换质量。这份脚本用**纯 numpy / CPU**
把其中六条摆到数字上，每条都做「解析真值 ↔ 数值反算」自校验。

## 如何运行

```bash
python3 run.py              # 跑全部六组，打印表格
python3 run.py 1 3          # 只跑第 1、3 组
python3 run.py --selftest   # 只跑断言（静默），适合挂 CI
```

依赖只有 numpy，固定 `seed = 20261014`，逐位可复现。共 30 条断言。

## 六组检查与结论

| # | 检查内容 | 结论 |
| --- | ---: | --- |
| 1 | FLOPs 记账：闭式公式 `L(3ND²+2N²D+ND²+2rND²+6D²) + 2Np²CD + …` 反算 DiT 论文 Table 4 | 13 个 Gflops 数字全部落在 0.5% 或论文两位小数颗粒度之内（最紧的一处用掉容忍度的 79%）；逐算子累加与闭式公式逐位相等。注意力二次项追平线性项的临界点是 `N* = (2+r)D = 6912` tokens；4K 图像下注意力占 82.4%，KV 压缩 s=2 后总 Gflops 从 82171 降到 31379 |
| 2 | 三种训练参数化（$$\epsilon$$ / $$x_0$$ / $$v$$）的互换恒等式 | 线性与余弦两条路径下四条恒等式的最大残差 8.9e-15。$$\epsilon$$ 预测到 $$x_0$$ 的误差放大因子是 $$\sigma/\alpha$$：t=0.9 时 9.00（余弦 6.31），t=0.99 时 99.0（余弦 63.7）；$$v$$ 预测的放大因子是 $$\sigma/\Delta$$，两条路径下都 ≤ 1 |
| 3 | AdaLN-Zero 的初始行为 | 28 层堆叠后 `max|out − x| = 0`（逐位恒等），同初始化下普通初始化偏离 37.78 倍；被门控掉的分支本身非零（Attn 分支 1.14 倍、MLP 分支 1.29 倍），$$\alpha$$ 的梯度非零且与中心差分吻合到 1e-9；输出层零初始化使初始损失精确等于目标自身能量 0.8107，普通初始化是 11.6910（14.42 倍） |
| 4 | 时间步的必要性 | 方差保持路径 + 单位方差数据下 $$x_t\sim\mathcal N(0,1)$$ 对所有 $$t$$ 成立（边缘分布完全不携带 $$t$$ 的信息），但已知 $$t$$ 的最优 MSE 是 0.5000，未知 $$t$$ 是 0.5949 —— 差 **18.99%**。同一输入 $$x_t=1.0$$ 在 t=0.2 / t=0.8 下的最优输出分别是 0.3090 与 0.9511，相差 0.6420 |
| 5 | 条件注入的表达力 | 全局向量条件能解释的能量恰好是 $$1/K$$：K=8 时 MSE 下界 0.875（闭式 $$1-1/K$$），K=2 时 0.500；硬选择交叉注意力 MSE = 0，softmax 交叉注意力经 3000 步梯度下降降到 7.8e-10 |
| 6 | 采样步数与求解器阶 | 高斯数据 + 线性路径有解析速度场 $$v^*(x,t)=\lambda(t)x$$，$$\int_0^1\lambda\,\mathrm dt=\ln(1/s)$$ 自校验通过。Euler 阶数实测 −0.92、Heun 实测 −2.11；折算到 DiT-XL/2，容限 1e-2 时 Heun 比 Euler 省 13.4 倍总算力，1e-3 时省 46.3 倍 |

## 哪些结论是这份脚本**没有**主张的

- 第 1 组只验证**前向乘加次数**，不涉及显存、访存、算子融合、kernel 效率。同样的 Gflops 在
  不同硬件上的延迟可以差一个数量级。
- 第 2 组的放大因子是**在给定 $$x_t$$ 与真实 $$(\epsilon, x_0)$$ 的前提下**推的，它说明「同样的
  预测误差在不同参数化下落到样本上有多大」，不等于「某个参数化的训练损失一定更低」——
  后者还取决于时间步采样分布与显式损失权重。
- 第 3 组的 28 层堆叠用的是 Kaiming 初始化的 numpy 版 DiT Block，**具体倍数依赖初始化尺度**；
  结论里与尺度无关的只有「AdaLN-Zero 下恒等性逐位成立、梯度不为零」这两条。
- 第 4 组是**一维高斯**上的贝叶斯最优解，它给出的是「丢掉 $$t$$ 的代价」的**下界量级**，
  真实图像上的数字会更大，但不会更小。
- 第 5 组用的是**正交单位范数的合成 token 嵌入**，衡量的是「路由容量」，不是真实文本编码器
  的语义几何。
- 第 6 组是**高斯 + 线性路径**上的解析流，真实数据的速度场非解析，二阶方法的常数会更差；
  这里只主张收敛阶与「步数 × 单次前向」的乘积结构。
