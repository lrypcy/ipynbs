# vae_core：VAE 核心机制的数值验证

对应文章：[《变分自编码器（01）：ELBO、重参数化与潜空间》](https://lrypcy.github.io/2026/10/13/vae-01-elbo-reparameterization-latent-space/)
（`lrypcy.github.io` 生成模型分类，VAE 系列第 1 篇）。

## 这份脚本回答什么

VAE 的几个论断长年以「人人都这么说」的形态流传，但很少有人把它摆到数字上。
这份脚本用**纯 numpy / CPU**把其中五条逐一钉死，每条都做「解析真值 ↔ 数值反算」自校验。

## 如何运行

```bash
python3 run.py              # 跑全部五组，打印表格
python3 run.py --selftest   # 只跑断言（静默），适合挂 CI
```

依赖只有 numpy，固定 `seed = 20261013`，逐位可复现。

## 五组检查与结论

| # | 检查内容 | 结论 |
| --- | ---: | --- |
| 1 | 高斯后验 KL 的闭式解 vs 蒙特卡洛估计 | 闭式解 1.484809 nats；N=2e6 的 MC 估计相差 9.6e-5，误差按 1/√N 收敛。闭式解不需要采样，也不需要用网络估计 |
| 2 | ELBO 的紧度恒等式 $$\log p_\theta(x)=\mathcal{L}_{\rm ELBO}+D_{\rm KL}(q_\phi(z\mid x)\Vert p_\theta(z\mid x))$$ | 随机 6 组 $$(q)$$ 的残差 ≤ 1.6e-15；1600 万个网格点上 $$\log p(x)-\text{ELBO}$$ 的最小值 2.96e-07 ≥ 0，下界性质成立；网格搜索出的最优 $$q$$ 与解析真后验相差 3.2e-04 |
| 3 | 重参数化梯度 vs score-function（REINFORCE）梯度 | 两者都无偏，但 REINFORCE 的方差是重参数化的 **7.6 ~ 56.2 倍**（同一目标、同一批样本） |
| 4 | 平方误差下的模态平均 | MSE 最优解就是两模态的逐像素平均：期望 MSE **0.0156**（选单模态为 0.0312，严格更差），但边缘锐度只有 **0.50**（真实模态 1.00）。「糊」是用锐度换期望误差的必然后果 |
| 5 | $$\beta$$ 扫描 | $$\beta$$ 从 0.25 升到 64：KL 总和 17.59 → 0.00006（单调下降），活跃潜维度 8 → 0（单调不升），重建 RMSE 0.317 → 1.053。KL 项是一把剪刀，后验坍塌是剪到 0 的极限 |

完整输出见 [`results/summary.md`](results/summary.md)。

## 哪些结论是这份脚本**没有**主张的

- 第 5 组用的是**线性高斯 VAE**上的全批量梯度下降，它只能演示「$$\beta$$ 越大压掉越多潜维度」。
  真正的后验坍塌（decoder 是强自回归模型时 $$q(z\mid x)\to p(z)$$）涉及解码器容量与自回归上下文，
  不在这份脚本的范围内，正文里也未把它当成实测结果。
- 第 4 组是**一维阶跃信号**上的构造性反例，用来说明「目标函数如何面对不确定性的机制」，
  不是真实图像上的重建实验。
- 训练循环里的 logvar 裁剪、梯度范数裁剪与学习率衰减都是**数值保护**，不改变优化目标。
