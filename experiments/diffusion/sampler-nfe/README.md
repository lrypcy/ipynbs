# sampler-nfe：扩散采样器的数值核验（DDIM / 中点法 / DPM-Solver-2）

对应文章：[扩散模型采样器：把反向过程写成 ODE 之后](https://lrypcy.github.io/2026/11/01/diffusion-sampler-ode/)

## 要验证的论断

| 组 | 论断 |
| --- | --- |
| A | 2D 八峰玩具的 score 与后验均值 $$x̂_0$$ 是解析的，且数值上符合 autograd / 归一化 / 大 $$t$$ 极限 |
| B | 换变量 $$\lambda=\log(\alpha/\sigma)$$ 后 $$d\lambda/dt=-\beta_t/(2\sigma_t^2)$$，链式法则给出 $$dx/d\lambda=\alpha(\hat x_0-\alpha x)$$ |
| C | DDIM 更新式就是「区间内 $$\hat x_0$$ 取常数」时的**精确**积分，两种常见写法逐元素同值 |
| D | 同预算下四个求解器的离散化误差排序，以及二阶方法在极低 NFE 反而更差 |
| E | 一阶方法误差斜率 ≈ 1，二阶 ≈ 2（含多步变体） |
| F | 取点规则与阶数必须配套：二阶偏好 uniform-$$\lambda$$，一阶偏好 uniform-$$t$$ |

## 运行

```bash

python sampler_lab.py D E             # 只跑指定组
python sampler_lab.py A --figdir DIR  # 额外输出 G 组（配图）
```

每组末尾自带断言，任一不满足立即中止，全部通过才输出 **断言总数 = 73**。

### 为什么玩具是 2D 八峰

比较求解器要的是「只有离散化误差，没有网络误差」。八峰高斯混合在 VP 前向之后
仍是高斯混合，于是 $$p_t$$、$$\nabla\log p_t$$、$$\mathbb E[x_0\mid x_t]$$ 全部有闭式，
换任何模型都做不到这么干净。同时八峰带多模态结构，能看出求解器把质量抹到峰间的那种错误。

### 三处不能省的细节

1. **时间必须是连续的**。脚本用线性 $$\beta(t)$$ 与闭式 $$\bar\alpha(t)=\exp\!\big(-\beta_0t-(\beta_1-\beta_0)t^2/2T\big)$$，
   而不是落到 1000 个整数步上。否则终点最小只能取到 $$t=1$$（$$\sigma\approx0.01$$），
   误差本底 1e-2 会把 NFE ≥ 40 之后的收敛全糊掉，阶数根本拟合不出来。
   改连续后终点取 $$t=10^{-2}$$，$$\sigma_{\rm end}=10^{-3}$$，本底降到 1e-3 以下。
2. **比的是「对同一批初值的高精度参考解」的偏差，不是分布距离**。两个有限样本之间的 sliced W2
   有正的本底（本机 8000 vs 8000 时约 0.092），NFE 一大就撞到本底上，曲线会假性走平甚至上翘。
   参考解用中点法在 4000 步上积分，自身误差远低于被测项；D 组同时打印了这个本底供对照。
3. **NFE 要按真实网络调用数记**。二阶方法每次迭代两次前向，所以 `nfe=80` 时它只走 40 步。
   断言里逐条核对实际调用数 ≤ 预算，否则「同预算对比」就是假的。

## 结果（`results/stdout.txt`，本机实跑）

### A–C：解析量与推导链

- 五个时间点上解析 score 与 autograd 的差都 < 1e-9；$$p_t$$ 的网格积分在 1e-3 内归一。
- $$t=T$$ 时 $$p_T$$ 方差 1.0020，$$\lambda$$ 区间 $$[-5.025,\ 6.907]$$，$$\sigma_{\rm end}=1.0\times10^{-3}$$。
- $$d\lambda/dt$$ 解析式与差分在 1e-5 内一致；链式法则给出的 $$dx/d\lambda$$ 与解析式差 < 1e-9。
- DDIM 的 $$u$$ 积分式与论文写法差 < 1e-12；给定真实 $$\epsilon$$ 时 $$\hat x_0$$ 能精确反解回 $$x_0$$。

### D：NFE 表（8000 个固定初值，误差 = 到参考解的平均 L2）

| NFE | Euler(x) | Midpoint(x) | DDIM | DPM-Solver-2 | DPM-Solver-2M |
| --- | --- | --- | --- | --- | --- |
| 5 | 0.56958 | 1.41092 | 0.72676 | 0.67829 | 1.65897 |
| 10 | 0.15900 | 0.66222 | 0.32630 | 0.09368 | 0.41949 |
| 20 | 0.06939 | 0.07766 | 0.15642 | 0.03720 | 0.06881 |
| 40 | 0.03219 | 0.02210 | 0.07654 | 0.01018 | 0.01431 |
| 80 | 0.01556 | 0.00601 | 0.03784 | 0.00339 | 0.00349 |

四个可以直接拿走的结论：

1. **NFE=80 时 DPM-2 比 DDIM 好 11.17×、比 x 空间欧拉好 4.59×**。
2. **二阶方法在极低预算下反而更差**：NFE=20 时 Midpoint(x) 0.07766 输给 Euler(x) 0.06939，
   到 NFE=40 才反超。因为每次迭代两次前向，步数直接少一半，交叉点在 20–40 之间。
3. **多步变体（每步 1 NFE）省一半算力，但起步段差**：NFE=10 时 0.41949 对单步的 0.09368，
   到 NFE=80 才追平（0.00349 对 0.00339）。
4. **DDIM 在粗网格上不占优**：它每一步都比 Euler(x) 差（80 步时 0.03784 vs 0.01556）。
   这不是实现写错了 —— C 组已经核对过更新式，原因是常数 $$\hat x_0$$ 假设的误差被 $$e^\lambda=\alpha/\sigma$$
   放大，而 $$\lambda$$ 大到 6.9 时这个因子接近 1000。

### E：收敛阶

| 求解器 | 斜率 | 误差 8 步 → 64 步 |
| --- | --- | --- |
| Euler(x) | 1.176 | 0.22806 → 0.019654 |
| DDIM | 1.048 | 0.41967 → 0.047422 |
| Midpoint(x) | 2.068 | 0.75006 → 0.009225 |
| DPM-Solver-2 | 1.889 | 0.22883 → 0.004859 |
| DPM-Solver-2M | 2.336 | 0.69127 → 0.005455 |

一阶两条都在 1.0–1.2，二阶两条在 1.9–2.1，与理论一致。**阶数相同不代表常数相同**：
DDIM 与 Euler(x) 同为 1 阶，误差差 2.4 倍；Midpoint(x) 与 DPM-2 同为 2 阶，差 1.9 倍。

### F：取点规则

| NFE | DDIM(t) | DDIM(λ) | DPM2(t) | DPM2(λ) |
| --- | --- | --- | --- | --- |
| 10 | 0.12915 | 0.32759 | 0.20390 | 0.09503 |
| 20 | 0.06563 | 0.15697 | 0.09066 | 0.03777 |
| 40 | 0.03400 | 0.07682 | 0.03571 | 0.01045 |

**同一个网格换一个求解器就换一个结论**：二阶偏好 uniform-$$\lambda$$（三步全胜），
一阶偏好 uniform-$$t$$（三步全胜）。所以「换 DPM-Solver 当求解器 + 保留原来的时间步」这种改法
并不能拿到论文里的收益，阶数与取点规则是一套东西。

## 结论

反向过程写成 ODE 之后，求解器的选择有两件事同时决定误差：**把线性部分解析积掉**
（DDIM 做的）与**把 $$\hat x_0$$ 在区间内的变化也积掉**（DPM-Solver 做的）。
只做前者，粗网格上会被 $$e^\lambda$$ 的放大赔回去；两件都做，NFE=80 时能拿到 11× 的改善。
