# ddpm-timestep：DDPM 时间步 / 调度 / 采样器的数值核验

对应文章：[DDPM 深度剖析：前向闭式、时间步与 DDIM 采样](https://lrypcy.github.io/2026/11/01/ddpm-deep-dive/)

## 要验证的论断

| 组 | 论断 |
| --- | --- |
| A | 逐步递推 $$t$$ 次与一步闭式是同一个分布（$$T=1000$$ 线性调度） |
| A2 | 闭式推导用到的三条代数关系（两层展开 / 归纳一步 / 望远镜求和），以及取对数后 $$\beta$$ 变加性 |
| B | $$t$$ 只决定噪声等级，同一个 $$t$$ 换一个 $$\epsilon$$ 是另一个实例；两者距离满足 $$2d(1-\bar\alpha_t)$$ |
| C | 后验均值的三种写法（论文式 / $$\epsilon$$ 式 / $$\hat x_0$$ 组合式）是同一个向量 |
| D | DDIM（$$\eta=0$$）的终点误差随 U-Net 调用次数单调下降；一步跳到位的误差被放大 $$\sqrt{(1-\bar\alpha_T)/\bar\alpha_T}$$ |
| E | 余弦调度把更多步数放在中等 SNR 区间，线性把一半以上预算花在近纯噪声段 |
| F | 同一份「50 步」预算，endpoint / stride / trailing 三种取点规则给出不同的时间步序列 |
| H | 随机项在模型完美时不起作用；有误差时它买的是多样性，不是精度 |

## 运行

```bash
python ddpm_lab.py                 # 全部 A、A2、B–F、H，约 26 秒
python ddpm_lab.py A2 C            # 只跑指定组
python ddpm_lab.py --figdir DIR    # 额外输出 G 组（博文配图）
```

环境：**PyTorch + CPU（torch 2.10.0）**，配图额外需要 matplotlib；固定种子 `20261101`。
纯 CPU，全量约 26 秒；每组末尾自带断言，任一条不满足立即中止，全部通过才会输出 **断言总数 = 87**。

### 为什么用 torch 而不是 numpy

调度、`q(x_t\mid x_0)`、DDIM 更新式在真实框架里都是逐元素张量运算，用 torch 写下来可以直接拿去跟 diffusers 的实现对照；`x_t` 的形状也和真实训练代码一致，后续想把 toy 升级成真 U-Net 不必重写数据管线。代价是逐步递推是纯 Python 循环，比 numpy 版慢（12 秒 → 30 秒）。

### 两处不能省的细节

1. **必须 float64**。脚本开了 `torch.set_default_dtype(torch.float64)`：默认 float32 下三种后验均值的差异会浮到 $$10^{-7}$$ 量级（float32 机器精度约 1.2e-7），再说「是同一个向量」就不严谨了。
2. **模型误差必须依赖当前状态**（取 $$\rho\,W x_t$$，$$W$$ 是固定的随机线性算子）。如果每步注入与 $$x_t$$ 无关的白噪声，那么
   $$\hat x_0=(x_t-\sqrt{1-\bar\alpha_t}\,\epsilon_\theta)/\sqrt{\bar\alpha_t}=x_0-\sqrt{1-\bar\alpha_t}\,\rho\xi/\sqrt{\bar\alpha_t}$$
   与历史无关，轨迹每步都在重置，最终结果只由最后一段决定——那种 toy 里 $$\eta$$ 和中间路径都不起作用，
   测出来的「步数越多越准」是假的。

## 结果（`results/stdout.txt`，本机实跑）

### A 组：逐步递推 vs 一步闭式（20 万条样本）

| $$t$$ | 均值偏差 | 方差偏差 |
| --- | --- | --- |
| 1 | 2.8e-05 | 3.1e-08 |
| 10 | 1.6e-04 | 3.3e-06 |
| 100 | 5.9e-04 | 2.2e-05 |
| 500 | 5.4e-03 | 3.6e-04 |
| 1000 | 2.4e-03 | 1.1e-03 |

偏差全部落在蒙特卡洛误差量级内；线性调度下 $$\bar\alpha_{1000}=4.04\times10^{-5}$$。

### A2 组：方差账本（闭式推导的三块砖）

四条断言全部对到浮点误差：两层展开 $$\alpha_t\beta_{t-1}+\beta_t=1-\alpha_t\alpha_{t-1}$$ 的误差 1.4e-16、归纳一步 $$\alpha_t(1-\bar\alpha_{t-1})+\beta_t=1-\bar\alpha_t$$ 的误差 2.2e-16、望远镜求和 $$\sum_s\beta_s\prod_{u>s}\alpha_u=1-\bar\alpha_t$$ 的误差 1.3e-15。

取对数后 $$\beta$$ 变加性：$$\sum\beta_s=10.0500$$、$$\tfrac12\sum\beta_s^2=0.0670$$，
于是 $$\exp(-\sum\beta-\tfrac12\sum\beta^2)=4.0386\times10^{-5}$$，与实测 $$\bar\alpha_T=4.0358\times10^{-5}$$ 的相对差是 $$6.8\times10^{-4}$$。
这也说明为什么单步的 $$\beta_T=0.02$$ 看起来很小：它加在 log 上只有 0.02，而 1000 步加起来是 10.05。

### B 组：同 $$t$$ 不同 $$\epsilon$$（$$d=8$$、$$t=500$$）

$$\bar\alpha_{500}=0.0786$$，两实例的**均方**距离实测与理论值 $$2d(1-\bar\alpha_t)=14.74$$ 相合（偏差 2.3e-3），对应的平均欧氏距离是 3.7219。

### C 组：后验均值的三种写法

$$t=2,50,300,900,1000$$ 上逐点比对，论文式 / $$\epsilon$$ 式 / $$\hat x_0$$ 组合式的最大差异 **2.4e-14**，$$\tilde\beta_t$$ 两种写法差异在 1e-17 量级。

### D 组：DDIM 的步数与误差（每步注入 1% 依赖状态的误差）

| U-Net 调用次数 | 1 | 2 | 5 | 10 | 20 | 50 | 100 | 200 | 500 | 1000 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 平均相对误差 | 5.9475 | 0.1363 | 0.0174 | 0.0055 | 0.0022 | 0.0008 | 0.0005 | 0.0003 | 0.0002 | 0.0001 |

单调下降，1000 步压到 1 步时的 **1.75e-05 倍**。oracle（无误差）时任意步数的相对误差 < 1e-8。
单步放大系数 $$\sqrt{(1-\bar\alpha_T)/\bar\alpha_T}=157.4$$，与实测窗口内的偏差 7.1e-15。

### E 组：线性 vs 余弦（$$T=1000$$、$$s=0.008$$）

| | 线性 | 余弦 |
| --- | --- | --- |
| $$\beta_t$$ @ t=1/100/300/500/1000 | 0.00010 / 0.00207 / 0.00606 / 0.01004 / 0.02000 | 0.00004 / 0.00053 / 0.00162 / 0.00315 / 0.999（clamp） |
| $$\bar\alpha_T$$ | 4.04e-05 | 2.43e-09 |
| SNR 首次 < 0 dB | t=260 | t=497 |
| SNR > 10 dB 的步数占比 | 9.3% | 18.8% |
| −10…10 dB 的步数占比 | 39.2% | **61.5%** |
| SNR < −10 dB 的步数占比 | **51.5%** | 19.7% |

### F 组：三种取点规则

$$N=5$$ 时分别给出 999,749,500,250,0 ／ 800,600,400,200,0 ／ 999,799,599,399,199；
$$N=50$$ 时最大时间步分别是 999 / 980 / 999，trailing 的最小值停在 19 而不是 0。

### H 组：随机项在做什么

- 随机项相对尺度 $$\sigma_t/\sqrt{1-\bar\alpha_{t-1}}$$：t=1000 时 14.1%，t=250 时 10.3%，t=10 时 38.4%，t=2 时 73.9%；第一步 $$\sigma_1=\sqrt{\beta_1}=0.01$$。
- oracle 下 $$\eta=0$$ 与 $$\eta=1$$ 都精确回到同一个 $$x_0$$（相对偏差 < 1e-8）。
- 注入 1% 误差后（8 组不同的 $$(x_0,x_T,W)$$ 各 10 条随机流）：$$\eta=0$$ 多样度恒为 0，$$\eta=1$$ 的多样度占终点偏差 49.2% / 28.1% / 15.8%（20 / 50 / 100 步）；平均误差比值 1.081 / 1.050 / 1.015。
- ⚠️ 这个比值**对随机种子不稳妥**（早期 numpy 版本测出的是 0.895 / 0.982 / 0.981，方向相反）。能写进结论的只有「同一个量级」，不能用来论证「随机项能/不能修复误差」。

## 结论

- A、B 两组是 DDPM 训练可行性的地基：任意 $$t$$ 可随机访问，且每个 $$t$$ 上模型只能学到条件均值。
- A2 组是闭式的代数地基：三处恒等式（含望远镜求和）都只差浮点误差，「$$\beta$$ 加性 / $$\alpha$$ 乘性」有定量版本 $$\sum\beta_s=10.05\Rightarrow\bar\alpha_T=4.04\times10^{-5}$$。
- C 组说明读代码时不必纠结用哪套系数，但要**承认 $$\hat x_0$$ 这条路的数值风险**：$$\bar\alpha_t\to 0$$ 时除以 $$\sqrt{\bar\alpha_t}$$ 会被放大。
- D 组把「少步 DDIM 为什么能用」归结为一个可算的量：误差被 $$\sqrt{(1-\bar\alpha)/\bar\alpha}$$ 放大，步数越多末段 $$1-\bar\alpha$$ 越小，这个系数越小；收益集中在前 20–50 步。
- E 组给余弦调度的流行提供了一个可核验的理由（预算分布），同时也点出它的代价（末端 $$\beta_T$$ 顶到 clamp）。
- F 组提醒：跨实现的「50 步」不可直接互比。
- H 组纠正常见表述：随机项不是用来「修复误差」的；$$\eta$$ 取舍的是多样性与确定性。
