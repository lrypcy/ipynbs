# ddpm-timestep：DDPM 时间步 / 调度 / 采样器的数值核验

对应文章：[DDPM 深度剖析：从理论到实践](https://lrypcy.github.io/2026/11/01/ddpm-deep-dive/)

## 要验证的论断

| 组 | 论断 |
| --- | --- |
| A | 逐步递推 $$t$$ 次与一步闭式是同一个分布（$$T=1000$$ 线性调度） |
| B | $$t$$ 只决定噪声等级，同一个 $$t$$ 换一个 $$\epsilon$$ 是另一个实例；两者距离满足 $$2d(1-\bar\alpha_t)$$ |
| C | 后验均值的三种写法（论文式 / $$\epsilon$$ 式 / $$\hat x_0$$ 组合式）是同一个向量 |
| D | DDIM（$$\eta=0$$）的终点误差随 U-Net 调用次数单调下降；一步跳到位的误差被放大 $$\sqrt{(1-\bar\alpha_T)/\bar\alpha_T}$$ |
| E | 余弦调度把更多步数放在中等 SNR 区间，线性把一半以上预算花在近纯噪声段 |
| F | 同一份「50 步」预算，endpoint / stride / trailing 三种取点规则给出不同的时间步序列 |
| H | 随机项在模型完美时不起作用；有误差时它买的是多样性，不是精度 |

## 运行

```bash
python ddpm_lab.py                 # 全部 A–F + H，约 12 秒
python ddpm_lab.py A C             # 只跑指定组
python ddpm_lab.py --figdir DIR    # 额外输出 G 组（博文配图）
```

环境：python 3 + numpy（miniconda base 即可，配图额外需要 matplotlib），固定种子 `20261101`。
每组末尾自带断言，任一条不满足立即中止；全部通过才会输出 **断言总数 = 83**。

> **误差模型的一个坑**：模型误差必须**依赖当前状态**（这里取 $$\rho\,W x_t$$，$$W$$ 是固定的随机线性算子）。
> 如果每步注入的是与 $$x_t$$ 无关的白噪声，那么
> $$\hat x_0=(x_t-\sqrt{1-\bar\alpha_t}\,\epsilon_\theta)/\sqrt{\bar\alpha_t}=x_0-\sqrt{1-\bar\alpha_t}\,\rho\xi/\sqrt{\bar\alpha_t}$$
> 与历史无关，轨迹每步都在重置，最终结果只由最后一段决定——那种 toy 里 $$\eta$$ 和中间路径都不起作用，
> 测出来的「步数越多越准」是假的。

## 结果（`results/stdout.txt`，本机实跑）

### A 组：逐步递推 vs 一步闭式（20 万条样本）

| $$t$$ | 均值偏差 | 方差偏差 |
| --- | --- | --- |
| 1 | 4.6e-05 | 2.2e-07 |
| 10 | 1.4e-04 | 3.6e-06 |
| 100 | 1.3e-03 | 8.4e-05 |
| 500 | 3.2e-03 | 1.4e-03 |
| 1000 | 5.7e-03 | 2.6e-03 |

偏差全部落在蒙特卡洛误差量级内；线性调度下 $$\bar\alpha_{1000}=4.04\times10^{-5}$$。

### B 组：同 $$t$$ 不同 $$\epsilon$$（$$d=8$$、$$t=500$$）

$$\bar\alpha_{500}=0.0786$$，两实例的**均方**距离实测与理论值 $$2d(1-\bar\alpha_t)=14.74$$ 相合（偏差 1.4e-2），对应的平均欧氏距离是 3.7235。

### C 组：后验均值的三种写法

$$t=2,50,300,900,1000$$ 上逐点比对，论文式 / $$\epsilon$$ 式 / $$\hat x_0$$ 组合式的最大差异 **1.8e-14**，$$\tilde\beta_t$$ 两种写法差异在 1e-17 量级。

### D 组：DDIM 的步数与误差（每步注入 1% 依赖状态的误差）

| U-Net 调用次数 | 1 | 2 | 5 | 10 | 20 | 50 | 100 | 200 | 500 | 1000 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 平均相对误差 | 5.7446 | 0.1365 | 0.0165 | 0.0051 | 0.0020 | 0.0008 | 0.0004 | 0.0003 | 0.0001 | 0.0001 |

单调下降，1000 步压到 1 步时的 **1.75e-05 倍**。oracle（无误差）时任意步数的相对误差 < 1e-8。
单步放大系数 $$\sqrt{(1-\bar\alpha_T)/\bar\alpha_T}=157.4$$，与实测窗口内的偏差 8.9e-16。

### E 组：线性 vs 余弦（$$T=1000$$、$$s=0.008$$）

| | 线性 | 余弦 |
| --- | --- | --- |
| $$\beta_t$$ @ t=1/100/300/500/1000 | 0.00010 / 0.00207 / 0.00606 / 0.01004 / 0.02000 | 0.00004 / 0.00053 / 0.00162 / 0.00315 / 0.999（clamp） |
| $$\bar\alpha_T$$ | 4.04e-05 | 2.43e-09 |
| SNR 首次 < 0 dB | t=260 | t=497 |
| SNR > 10 dB 的步数占比 | 9.3% | 18.8% |
| −10…10 dB 的步数占比 | 39.2% | **61.5%** |
| SNR < −10 dB 的步数占比 | **51.5%** | 19.7% |

### F 组：三种取点规则

$$N=5$$ 时分别给出 999,749,500,250,0 ／ 800,600,400,200,0 ／ 999,799,599,399,199；
$$N=50$$ 时最大时间步分别是 999 / 980 / 999，trailing 的最小值停在 19 而不是 0。

### H 组：随机项在做什么

- 随机项相对尺度 $$\sigma_t/\sqrt{1-\bar\alpha_{t-1}}$$：t=1000 时 14.1%，t=250 时 10.3%，t=10 时 38.4%，t=2 时 73.9%；第一步 $$\sigma_1=\sqrt{\beta_1}=0.01$$。
- oracle 下 $$\eta=0$$ 与 $$\eta=1$$ 都精确回到同一个 $$x_0$$（相对偏差 < 1e-8）。
- 注入 1% 误差后（8 组不同的 $$(x_0,x_T,W)$$ 各 10 条随机流）：$$\eta=0$$ 多样度恒为 0，$$\eta=1$$ 的多样度占终点偏差 52.9% / 29.3% / 15.6%（20 / 50 / 100 步）；平均误差比值 0.90 / 0.98 / 0.98。

## 结论

- A、B 两组是 DDPM 训练可行性的地基：任意 $$t$$ 可随机访问，且每个 $$t$$ 上模型只能学到条件均值。
- C 组说明读代码时不必纠结用哪套系数，但要**承认 $$\hat x_0$$ 这条路的数值风险**：$$\bar\alpha_t\to 0$$ 时除以 $$\sqrt{\bar\alpha_t}$$ 会被放大。
- D 组把「少步 DDIM 为什么能用」归结为一个可算的量：误差被 $$\sqrt{(1-\bar\alpha)/\bar\alpha}$$ 放大，步数越多末段越接近 1，这个系数越小；收益集中在前 20–50 步。
- E 组给余弦调度的流行提供了一个可核验的理由（预算分布），同时也点出它的代价（末端 $$\beta_T$$ 顶到 clamp）。
- F 组提醒：跨实现的「50 步」不可直接互比。
- H 组纠正常见表述：随机项不是用来「修复误差」的；$$\eta$$ 取舍的是多样性与确定性。
