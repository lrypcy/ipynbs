# few-step：少步生成（一致性模型 / 蒸馏）的数值核验

对应文章：[扩散模型的少步生成：一致性模型到底把什么换成了步数](https://lrypcy.github.io/2026/11/01/diffusion-few-step/)

## 要验证的论断

| 组 | 论断 |
| --- | --- |
| A | 1 步生成的信息量完全够：精确一致性函数做 1 步就与真分布不可区分。塌缩的不是「1 步」，是**把 DDPM 的后验均值 $$x̂_0$$ 当生成器**——它在噪声端只剩数据标准差 1.50% |
| B | 自一致性损失有整族零解：$$f_h=β f^*$$ 对任意 β 损失都 $$<10^{-5}$$，而 1 步误差随 $$\lvert 1-β\rvert$$ 线性增长。边界条件不是工程细节，是唯一消除退化的东西 |
| C | 步数不修复错的映射。**系统偏差**（偏置 / 收缩）随步数单调放大 5–7 倍，**零均值误差**被摊平，**丢掉的模态**是死地板 |
| D | 一致性训练（CT）用相邻格点近似轨迹，偏差在细网格上一阶收敛（斜率 1.18），粗网格超出一阶；方向恒为「朝均值收缩」 |
| E | 训练期 NFE 账本：CD 摊销到 1 NFE/对、PD 约 $$2N_0$$；学生第 1 步起就偏离教师轨迹，偏离幅度 23% 数据标准差 |

## 运行

```bash
python few_step_lab.py                 # 全部 A–E，约 60 秒
python few_step_lab.py A C             # 只跑指定组
python few_step_lab.py A --figdir DIR  # 额外画图
```

环境：**纯 numpy**（不需要 GPU，也不训练任何网络）；配图额外需要 matplotlib。
固定种子 `20261104`，全部通过才输出 **断言总数 = 36**。

### 为什么不用小网络训练

本实验要测的不是「我的训练脚本能不能收敛」，而是「近似误差的**形态**如何随步数兑现」。
在 4 模态一维高斯混合上，score、后验均值、概率流 ODE 全部闭式，于是可以把「学生」写成

$$f_θ(x,t)=\underbrace{f^*(x,t)}_{数值积分的精确一致性函数}+\text{已知形态的扰动}$$

扰动本身成为唯一变量：偏置、收缩、丢模态、零均值抖动。换成一个小网络，
「扰动」就变成不可分解的混合体，测出来的数字无法归因。

### 三处不能省的细节

1. **λ 与 t 的互换写错符号，数值会「看起来收敛」**。$$\barα=1/(1+e^{-2λ})$$ ⇒ $$-\\log\barα=\\log(1+e^{-2λ})$$。
   若误写成 $$\\log(1+e^{+2λ})$$，积分步数从 128 加到 2048 输出完全不变（自洽），
   但整条轨迹跑在 α、σ 互换的场里；只有线性高斯那组有闭式解对照，才会暴露。
2. **「精确一致性函数」必须是 ODE 端点，不是 $$x̂_0$$**。两者都满足 Tweedie 恒等式，
   但在噪声端输出标准差相差 380 倍。代码里 `endpoint_map` 从 λ 积分到 `LAM_END`；
   `x0hat` 只作为塌缩的对照物出现。
3. **多步采样里 f 的调用次数要和 K 严格对齐**。最后一步不再加噪、直接输出 $$x_0$$ 估计，
   所以 K 步恰好 K 次调用。早一版在循环外又调了一次 f，K=1 时偏置被施加两次，
   表里「偏置 0.05、K=1」的 W1 就虚高到 0.169（正确值 0.121）。

## 结果

### A：1 步到底缺什么

| 量 | 值 |
| --- | --- |
| 1 步 $$x̂_0$$ 的标准差 / 数据标准差 | **1.50%** |
| 1 步 $$x̂_0$$ 与数据的 W1 | 1.965（≈ 数据自身平均绝对离差 1.986，即全部塌缩到均值） |
| 精确一致性函数 1 步的 W1 | **0.0184**（W1 噪声地板 0.0265，即 0.69×） |
| 方差比 / 四模态质量偏差 | 1.0059 / ≤0.008 |

纯高斯上塌缩率有闭式 $$ρ(t)=\frac{α_tσ_d}{\sqrt{v_t}}$$（$$v_t=α_t^2σ_d^2+σ_t^2$$），数值验到 2.45e-3。

### B：自一致性损失的零解族

| β | 0 | 0.25 | 0.5 | 0.75 | 1.0 | 1.25 |
| --- | --- | --- | --- | --- | --- | --- |
| 一致性损失 | ~0 | ~0 | ~0 | ~0 | ~0 | ~0 |
| 输出 sd 比 | 0.000 | 0.250 | 0.500 | 0.750 | 1.000 | 1.250 |
| 1 步 W1 | 1.973 | 1.465 | 0.957 | 0.451 | **0.072** | 0.574 |

损失的最大值 5.4e-7（数据尺度 2.24 的 2.4e-7 倍）；W1 严格是 V 形，底部在 β=1。

### C：步数 × 缺陷（W1，2500 样本）

| 缺陷 | K=1 | K=2 | K=4 | K=8 | K=16 |
| --- | --- | --- | --- | --- | --- |
| 精确 $$f^*$$ | 0.075 | 0.083 | 0.100 | 0.043 | 0.070 |
| 偏置 δ=0.05 | 0.121 | 0.173 | 0.247 | 0.280 | 0.547 |
| 偏置 δ=0.15 | 0.218 | 0.359 | 0.552 | 0.822 | **1.549** |
| 收缩 15% | 0.314 | 0.513 | 0.742 | 1.086 | **1.549** |
| 丢一个模态 | 0.925 | 0.912 | 0.919 | 0.984 | 0.956 |
| 零均值抖 0.15 | 0.073 | 0.085 | 0.096 | 0.076 | 0.118 |

丢模态那一行的死地板来自 x=+3 处质量恒为 0.000–0.002（数据 0.250）：
模态一旦没学到，**任何步数都不恢复**。

两种多步采样（收缩 15%，K=16）：随机重加噪 **1.543**，确定性 **0.758**。
有系统偏差时确定性更好——它只在最后一步用一次 f，随机版每步都重新注入同一份偏差。

### D：CT 的离散化偏差

| N | Δt | 平均 $$\lvertΔx̂_0\rvert$$ | std(粗)/std(细) |
| --- | --- | --- | --- |
| 8 | 1.25e-1 | 4.05e-1 | 0.945 |
| 32 | 3.12e-2 | 4.18e-2 | 0.780 |
| 128 | 7.81e-3 | 3.28e-3 | 0.929 |
| 1024 | 9.76e-4 | 2.78e-4 | 0.990 |

Fine-grid log-log 斜率 1.183（一阶），全域 1.59（粗网格超出一阶，因为 Δt 大到估计已跨过模态边界，
$$x̂_0$$ 在那里是跳跃的）。std 比恒小于 1：偏差方向是把粗格点的值当细格点的目标 → 学生被往均值拽。

### E：账本与路径错配

| 方法 | 每样本训练成本 |
| --- | --- |
| CD（一致性蒸馏） | 1 教师 NFE / 对（与教师步数无关，完全摊销） |
| CT（一致性训练） | 0 教师 NFE / 对 |
| PD（渐进蒸馏，4 轮自 16 步） | 30 = $$2N_0(1-2^{-r})$$ ≈ 与 CD 同量级 |

路径错配（收缩 15%，K=8，确定性多步），学生第 k 步落点与教师轨迹的平均偏离：
`0 → 0.031 → 0.137 → 0.387 → 0.420 → 0.170 → 0.241 → 0.382 → 0.524`（数据标准差 2.26 的 23%）。

## 四条结论

1. **1 步不缺信息**。精确一致性函数 1 步的 W1 是 0.0184，比采样噪声地板还低。
   「1 步一定糊」是把后验均值 $$x̂_0$$ 误当生成器的结果，那个东西的标准差只有数据的 1.5%。
2. **损失管不了对错**。自一致性损失对 $$f_h=βf^*$$ 恒为 0，而 1 步误差随 $$\lvert 1-β\rvert$$ 线性增长。
   参数化里的 boundary（$$c_{\rm skip}(t_{\rm end})=1,\ c_{\rm out}(t_{\rm end})=0$$）就是那个把零解族钉成唯一解的约束。
3. **步数修复方差，不修复偏差**。同样是 0.15 的误差：零均值抖动多走几步还是 0.118，
   系统偏置多走几步涨到 1.549。少步生成的全部难点在「学生的映射错在哪」，不在「用了几步」。
4. **模态丢失是死地板**。丢一个模态后 1 步与 16 步的 W1 都是 0.91–0.98，该模态的质量恒为 0.000–0.002。
   这比任何 FID 数字都更清楚地说明：少步蒸馏的失败模式是「少了一个峰」，不是「糊了一点」。
