# acceptance_model：投机解码的收益模型

对应文章：[《投机解码（02）：收益模型 —— α、γ、c 三个数决定一切》](https://lrypcy.github.io/2026/10/18/specdec-02-acceptance-and-speedup-model/)
（`lrypcy.github.io` 推理服务分类，specdec 系列第 2 篇）。

## 这份脚本回答什么

投机解码的收益由三个数决定：单步接受概率 $$\alpha$$、草稿长度 $$\gamma$$、
草稿与目标单次前向的耗时比 $$c$$。这三个数怎么组合出最终加速比，
「$$\gamma$$ 该设多大」有没有普适答案，以及收益的硬天花板在哪——这份脚本把它们摆到数字上。

用**纯 numpy / CPU** 跑了三组，每组都做「解析真值 ↔ 数值反算」自校验。

基础设定沿用 Leviathan et al. 的 draft → verify 两阶段范式（独立接受假设）：

- 每轮产出 token 数期望 $$\mathbb{E}[T] = (1 - \alpha^{\gamma+1}) / (1 - \alpha)$$
- 每轮耗时（以目标模型单次前向为单位）$$1 + \gamma c$$
- 加速比 $$S(\alpha, \gamma, c) = \dfrac{1 - \alpha^{\gamma+1}}{(1 - \alpha)(1 + \gamma c)}$$

## 如何运行

```bash
python3 run.py              # 跑全部三组，打印表格
python3 run.py --selftest   # 只跑断言（静默），适合挂 CI
python3 run.py 1 2          # 只跑第 1、2 组
```

依赖只有 numpy，固定 `seed = 20261018`，逐位可复现。

## 三组检查与结论

| # | 检查内容 | 结论 |
| --- | ---: | --- |
| 1 | 蒙特卡洛模拟 draft-verify 过程，与 $$\mathbb{E}[T]$$ 闭式对拍（15 格） | 最大相对误差 **0.1252%**，闭式成立。$$\alpha=0$$ 时 $$S<1$$：草稿全被拒却仍要付 $$\gamma c$$ 的账 |
| 2 | $$\gamma^*$$ 与 $$S^*$$ 的网格枚举（25 格，$$\gamma$$ 上界 64）+ 三条交叉验证 | 24 个内部解与解析一阶条件一致；$$\gamma^*$$ 随 $$c$$ 单调不增、随 $$\alpha$$ 单调不减；最优 $$S$$ 恒 $$\ge 1$$ |
| 3 | 两条极限边界 | $$c \to 0$$ 时 $$S \to (1-\alpha^{\gamma+1})/(1-\alpha)$$；$$\alpha \to 1$$ 时 $$S \to (\gamma+1)/(1+\gamma c)$$。相对误差均 $$< 10^{-4}$$ |

### γ* 与 S* 网格（α 行 × c 列）

| $$\alpha \backslash c$$ | 0.01 | 0.05 | 0.10 | 0.20 | 0.50 |
|---:|---|---|---|---|---|
| 0.40 | γ*=4, S=1.59 | γ*=2, S=1.42 | γ*=2, S=1.30 | γ*=1, S=1.17 | **γ*=0, S=1.00** |
| 0.60 | γ*=7, S=2.30 | γ*=4, S=1.92 | γ*=3, S=1.67 | γ*=2, S=1.40 | γ*=1, S=1.07 |
| 0.80 | γ*=14, S=4.23 | γ*=8, S=3.09 | γ*=6, S=2.47 | γ*=4, S=1.87 | γ*=2, S=1.22 |
| 0.90 | γ*=24, S=7.49 | γ*=13, S=4.67 | γ*=10, S=3.43 | γ*=7, S=2.37 | γ*=3, S=1.38 |
| 0.95 | γ*=40, S=12.54 | γ*=21, S=6.60 | γ*=15, S=4.48 | γ*=10, S=2.87 | γ*=5, S=1.51 |

**一句话结论**：$$\gamma^*$$ 对 $$c$$ 极度敏感 —— 同一个 $$\alpha$$ 下，$$c$$ 从 0.01 涨到 0.50
会把 $$\gamma^*$$ 压掉一个量级。所以「$$\gamma$$ 该设多大」没有普适答案，
它由 $$c$$ 决定，而 $$c$$ 取决于草稿器形态（EAGLE 单层解码器 vs 独立小模型）。

另一个更硬的结论：$$1/(1-\alpha)$$ 是加速比的**天花板**，与 $$\gamma$$ 无关。
$$\alpha=0.9$$ 时天花板就是 10，无论草稿多长、多便宜都过不去。

完整输出见 [`results/summary.md`](results/summary.md)。

## 哪些结论是这份脚本**没有**主张的

- **独立接受假设**。组 1 的闭式与模拟都建立在「每个草稿 token 以固定概率 $$\alpha$$ 独立被接受」上。
  真实的 $$\alpha$$ 随位置、上下文、batch 变化（EAGLE-2 的核心观察就是这一点），
  因此这张表是**上界参考**，不是实测加速比。
- $$c$$ **不是常数**。它随 batch、序列长、硬件、草稿器实现而变；
  脚本把它当作外生给定的参数扫描，不预测任何具体系统的 $$c$$ 值。
- **不主张任何实测加速比数字**。全篇没有跑过一次真实的 draft-verify 推理。
- $$\alpha = 0.40, c = 0.50$$ 那格给出 $$\gamma^*=0$$（即不开投机），
  这是模型内的结论，不是「某具体模型上投机无效」的证据。
- 树验证（SpecInfer / EAGLE-2 动态树）会改变接受长度的几何结构，
  **不在**本脚本的独立序列假设内。
