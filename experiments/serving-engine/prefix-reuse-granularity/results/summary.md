组 1  对齐损失的闭式与数值对拍  (B = 16)
====================================================================
  L ~ 离散均匀 U[1, 4096]，样本 N = 400000

  量                                      蒙特卡洛           解析真值
  ----------------------------------------------------------
  E[L mod B]  (平均损失)                 7.503692       7.500000
  E[L]                            2047.894652    2048.500000
  相对损失率                              0.366410%      0.366122%

  恒等式 block_reuse(L) + loss(L) == L  : 9 个探测点全部成立
  L 为 B 的整数倍时 loss == 0           : 257 个探测点全部成立
  单周期内 loss(L) == L mod B           : 16 个探测点全部成立

  结论：对齐损失就是 L mod B 本身，与 L 的绝对大小无关；
        它是一笔「最多 B-1 = 15 token」的固定小额税，不是比例税。

组 2  三种典型负载下的加权复用率  (B = 16)
====================================================================
  负载                                       E[L]        块式复用率          损失率
  --------------------------------------------------------------------
  均匀前缀 U[64, 2048]                      1055.18     99.2894%      0.7106%
  共享长系统提示 1024 + U[0,128]               1088.09     99.3166%      0.6834%
  多轮对话 256 * U[1,8] + U[0,64]           1183.68     99.3761%      0.6239%
  短对话 U[16, 128]                          71.95     89.6613%     10.3387%

  自校验（加权复用率落在 [0, 1]，且块式不高于 token 式）：
    4 条负载的复用率全部落在 [0, 1]，块式恒不高于 token 式

  结论：损失率随「前缀越短」单调放大。
    最吃亏：短对话 U[16, 128]，损失率 10.3387%（E[L] = 71.95）
    最不吃亏：多轮对话 256 * U[1,8] + U[0,64]，损失率 0.6239%（E[L] = 1183.68）

  读法：块对齐是一笔绝对额不超过 15 token 的税，分母越小它越显眼。
        因此「16 对齐损失很大」这个说法只在短前缀负载上成立。

组 3  定长块的内部碎片  (B = 16)
====================================================================
  L ~ 离散均匀 U[64, 2048]，样本 N = 200000

  量                                           值
  ----------------------------------------------
  E[L]                                1057.4197
  E[占用]（块对齐后）                         1064.9214
  平均内部碎片率                                1.2602%
  同容量驻留请求数比（块/token）                   0.992956

  恒等式：占用 >= L 恒成立；单块内碎片 = (B - L) / B 逐点成立；
          L 为 B 的整数倍时碎片恰为 0。

  结论：平均碎片率 1.26%，即每 100 个 token 的 KV 里约有 1.26 个
        存了但永远读不到；同容量下驻留请求数是 token 级的 0.9930 倍。

  这一组只主张结构：碎片来自「分配粒度 != 复用粒度」，
  具体倍数取决于真实请求长度分布，不主张任何实测显存数字。
