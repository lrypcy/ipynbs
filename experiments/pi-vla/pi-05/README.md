# pi-05：把子任务折进同一个模型，共训练到底补了什么

对应文章：π 系列具身模型（05）π0.5（arXiv 2504.16054）。

Hi Robot 用**两个模型、两套权重**把长程指令拆成子任务；π0.5 问的是能不能折进
**一个模型**：先让同一套权重说出下一步的子任务文本，再让它的 action expert 生成动作块。
但论文真正的赌注不在这一步，而在**异构共训练（heterogeneous co-training）**：
用一个模型把「网页上的语义知识」「别的机器人 / 别的家里的动作」「目标平台上的演示」
一起吃进去，让它在一个**没见过的房子**里做几十步的家务。

本实验在 04 篇的合成世界上加三个结构，把论文里最容易含混过去的四件事钉死：

1. **web 数据补的是语义，不是动作。** 观测只给外观 $$\phi_t$$，决策要用语义属性
   $$z_t$$；机器人演示里只出现 7 个类型，另外 3 个类型只在 web 数据里出现过。
   直接监督 $$\psi(\phi)\to z$$ 还不够——技能头 / 共享主干也要见过这些属性模式，
   所以 web 批里有一半是**纯语义问答**（问「这个属性组合该选哪个技能」，不给动作）。
2. **多环境数据补的是「怎么做」，不是「做什么」。** 环境上下文 $$\kappa$$ 通过固定的
   **非线性**映射 $$u(\kappa)$$ 进动作；环境数从 3 增到 100，技能准确率几乎不动，
   但新环境下的动作误差从 0.356 掉到 0.166——**两条曲线必须分开看**。
3. **共训练的收益几乎全在分布外。** 完整配方在分布内的端到端误差（0.271）
   并不比只用目标平台数据（0.268）好；差距只出现在未见类型与未见环境上。
4. **两阶段推理是收益的来源，也是单点故障。** 分布内 joint 最好（0.271 < 0.303），
   但遇到未见过的复合约束时，预测出的离散子任务一旦错，后面全错：
   joint 1.159 / implicit 1.005 / flat 0.761。**只共训练、部署时不跑高层（implicit）
   拿不到分布内收益**，还因为技能头分走容量而比 flat 更差。

**只验机制，不重算论文成绩**：真实家庭的 long-horizon 成功率、约 400 小时数据、
预训练 280k / 后训练 80k 步都是引用，见文章 §5 / §9。

## 合成世界

桌上有 $$K=5$$ 个槽，每个槽放一个**类型** $$t\in\{0,\ldots,9\}$$：7 个 seen 类型出现在
机器人演示里，3 个 web-only 类型只在 web 数据里出现。每个类型有一组互异的 4 位二值语义属性
$$z_t\in\{\pm1\}^4$$，观测给的是随机单位外观向量 $$\phi_t\in\mathbb{R}^8$$，
模型要靠槽编码器 $$\psi:\phi\mapsto\hat z$$ 把语义恢复出来。

- 用户指令是作用在属性位上的筛选谓词（约束 $$c$$），编码成 $$4\times3$$ 逐位 one-hot。
  训练集是 8 个单位谓词，测试集是 4 个「两位合取」的复合谓词——复合约束
  **不进任何训练集**（CE 泄漏是上一版的 bug）。
- 真值技能 $$s^\star$$ 由 $$W_g$$ 在目标物体的属性上打分选出（6 个技能，含 done）。
- 真值动作 $$a^\star=\mu_{s^\star}+Bx+(v\cdot x)\,u(\kappa)+\eta$$，
  $$u(\kappa)=C\kappa+\tanh(\kappa W_2^\top)C_2^\top$$；环境项与 $$Bx$$ 项标定到同量级
  （$$0.25/D_A=0.0310$$），$$\eta$$ 给出不可约噪声。
- 模型是单套权重两个头：$$\psi$$（每槽共享）→ trunk → 技能头（CE）与动作头（MSE）。
  `joint` 两阶段（动作头看预测技能）、`implicit` 训练带技能头但部署时动作头直接看约束、
  `flat` 连技能监督都没有。

数据配方对应论文的六类来源：每个 step 都有一批 MM 目标平台动作（技能 CE + 动作 MSE）；
其中 $$r<0.35$$ 的步把 ME 的额外环境并进采样池。$$0.35\le r<0.65$$ 的 30% 步再加一批
CE 跨本体 / 更多任务的**纯技能**监督（不给动作）；$$r\ge0.65$$ 的 35% 步加 WD web 语义批，
其中一半是 $$\psi(\phi)\to z$$ 直接监督，一半是覆盖全部属性模式的语义问答（也不给动作）。
VI（语言指令）没有单独的合成对应物——探针里所有约束都是符号化的，这是边界之一（见下）。

## 边界

- **CE 的负结果必须这样读**：探针里所有本体的动作空间都是同一个 8 维空间，
  只有约束 / 环境 / 类型分布不同。论文里 CE（含 OXE）真正提供的是**跨本体动作语义的
  对齐**，本实验没有建模这一层，所以「拿掉 CE 几乎不掉点」是**探针的结论**，不是
  对论文消融的复现。文章 §10 也按这个口径写。
- 网络是两层 MLP（隐藏 64），不是 2B PaliGemma VLM + 300M action expert；
  flow matching 被换成动作 MSE，**离散 FAST token 与连续向量场两套表示的共存没建模**。
  「网页预训练的语言先验」在这里退化成一张 $$(\phi,z)$$ 对应表和语义问答。
- 环境上下文 $$\kappa$$ 直接进动作头；论文里「新家」是通过图像进入 VLM 的，
  这里没有视觉编码器，所以只测「环境数量对函数 $$u(\cdot)$$ 的可辨识性」这一半。
- 高层子任务是 6 分类的技能 id，不是自由文本；**文本接口的可解释、可注入、
  措辞漂移（04 篇 C 组）这里都没有建模**。
- B 组的「对照（含测试环境）」是把测试环境也放进训练池，对应论文 Fig.8 的 green control；
  它不是一个可部署的基线，只用来给 scaling 曲线一个上界。
