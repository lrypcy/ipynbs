# pi-09：MEM 的「短时视频记忆 + 长时文本记忆」分工

对应文章：π 系列具身模型（09）MEM（arXiv:2603.03596v2，
*MEM: Multi-Scale Embodied Memory for Vision Language Action Models*，
全文缓存 `09.html` / `09.txt`，事实只取事实清单 `09_mem.md`）。

MEM 把两种时间尺度的记忆接进同一个 VLA：低层 π_LL 看**数秒的密集视频历史**
（补遮挡、理解动力学），高层 π_HL 读写**几分钟尺度的自然语言事件摘要** m_t
（记住哪些子任务已完成 / 哪些配料已加 / 记得关被打开的柜门）。本实验不重算
真机成绩，只把「两类记忆凭什么分工、各在什么条件下失效」拆成可解析合成世界。

## 合成世界

两个时间尺度共用一套线性高斯 / 离散世界，纯 numpy、CPU、固定 seed、40 个
seed 平均、每组末尾断言、最后打印断言总数。

**短时侧（A / B / D 的遮挡任务）**：K 帧历史里每帧藏一个标量状态 h_k。
video encoder 抽象成一张固定的**正交 DCT-II（正弦 temporal position encoding）
线性映射** A(K) ∈ R^(B×K)：无论 K 多大，表示永远只有 **B=12 行**（对齐「token
数不增」），秩 = min(K,B)。对照的「全连接 attention」在同样 B 个槽里**只能保留
最近 B 帧**、旧帧整体丢弃 —— 这是本探针的建模假设，不是论文声称的实现；
论文 §III-C 的对应事实是「朴素逐帧塞入 backbone 会迅速超出实时延迟阈值」。
自校验：DCT 正交性、rank=min(K,B)、span=(K−1)·Δ、帧间事件可恢复比例
min(1, 2w/Δ) 的解析 ↔ MC 反算、线性高斯后验增益 g*=1/(1+σ²) 的手写 ↔ 有限差分。

**遮挡任务（B / D）**：物体藏在 L=8 个「抽屉」之一，当前帧被遮挡；清晰的历史帧
给观测 y = a_clear·e_j + η（a=1.0），被遮挡的当前帧只给弱线索（a=0.3），
η∼N(0, σ²)，σ=0.4。argmax 判别的正确率有确定性积分闭式
P(correct)=∫φ(z)Φ(z+a/σ)^(L−1)dz，a=0 时精确等于 1/L。三种条件：
无记忆（a=0）、只当前帧（a=0.3）、有视频记忆（a=1.0，仅当最后一次可见帧
距当前 d < K 时成立）。

**长时侧（C / D 的阶段任务）**：N=15 个阶段、每阶段 60 秒（15 分钟是论文引用，
N 与 60 秒自设）。每阶段有一个要被回忆的**关键标记 bit**（如「已加皂 / 柜门已关」），
外加 ρ=1 个**冗余标签**（失败重试 / 颜色细节）。原始标签流共 30 条，文本记忆
buffer 容量 L_max=15。压缩强度 α 优先删冗余、再删最旧的阶段标记；π_HL「失败
子任务不更新记忆」等价于冗余从不写入。判别任务：随机问一个历史阶段的标记，
二值 → 机会基线 0.5。视频记忆窗口 W=54 秒 < 阶段 60 秒，最多只看见 1 个标记。

## 反直觉结论（写正文须照此口径）

1. **A 组：固定 token 预算下，两种注意力的信息总量相同。** 时空分离与全连接的
   总重建 MSE 逐点相等（都是 B=12 个标量槽）；差别在**误差分布**：分离把误差摊平
   到整个跨度，全连接把误差全部集中到远端帧。平均符号判别准确率 K=18 时
   0.7973 / 0.7914 相差很小，**平均指标分不开二者**；只有「最差帧 / 远期召回」
   能分开（0.7750 vs 0.5000 随机）。而全连接在**近端帧**反而比分离的任意一帧都准
   （0.9372 vs 0.8934）。所以论文的价值不是「塞进更多信息」，而是「不丢远期 +
   O(Kn²+nK²) 省算力」。
2. **A 组：跨度不是免费的。** token 数不增时靠加大 Δ 把 span 从 17 s 拉到 51 s，
   帧间事件可恢复比例按 2w/Δ 从 1.0000 掉到 0.3333 —— 对应论文 5 秒 → 54 秒
   horizon 扩展的同时，时间分辨率下降。
3. **B 组：跨度买的是覆盖范围，不是精度。** K 从 6 增到 18，窗内 d=1 的补偿
   精度不变（均 0.8352）；它只是把「不失效」的遮挡时长上限从 d<6 推到 d<18。
   d≥K 时不是塌到随机 0.1250，而是**退化到「只当前帧」0.3068**（弱线索还在）。
4. **C 组：压缩是倒 U 形，不是越狠越好、也不是不压缩最好。** 峰值 α*=0.500
   恰在「冗余全删、阶段标记一个不丢」处（1.0000）；naive 拼接所有历史因失败重试
   冗余挤掉旧阶段只有 0.7333，压缩过头 α=1 退化到 0.5000。π_HL「失败不更新记忆」
   等价于自动完成这一步（α=0 也拿到 1.0000）。
5. **C / D：两类记忆互补，不是叠加。** 「两者都有」在单项任务上**等于**对应的
   单项记忆（长程阶段 = 只文本 1.0000；遮挡 = 只视频 0.8352），没有叠加增益，
   也没有 Fig.9 担心的性能退化；它的价值是**唯一**同时在两类任务上都取到各自最佳
   水平的配置。长时文本对遮挡完全无效（0.1250 = 机会），短时视频对长程几乎无效
   （0.5333 vs 0.5000，差 0.0333）。

## 边界（本探针没建模什么）

- 世界是**线性高斯 + 离散阶段**，不是 Gemma3-4B VLM + 860M action expert 的
  transformer；flow matching、离散 FAST action token、4 路 448×448 相机流、
  RTC 异步实时推理全部没有建模。video encoder 被抽象成「固定正交映射 + 窗内
  充分统计量」，忽略了 sketch 随遮挡时长的衰减，也忽略了「每 4 层」的层级堆叠
  细节（只用 12 层 / 3 个 temporal 层做一个结构自校验）。
- 「全连接 attention 只能保留最近 B 帧」是本探针为公平比较设的建模假设；
  论文的对应事实是复杂度与延迟（Fig.2 / §III-C），不是这个具体截断实现。
- A 组把 token 预算抽象成 B 个标量槽；论文只说「token 数不增、上层丢弃历史
  token、过去本体状态产生 K 个 proprioceptive state token」，更细的 token 数、
  层数、隐藏维度、推理延迟毫秒数**论文未给出**。
- B 组把遮挡抽象成「一段历史里有一帧清晰可见」；论文没有独立编号的遮挡实验，
  也没有对应数值，只有 §III-C 的定性表述与 Fig.7 的部分可观测任务。
- C 组把 π_HL / LLM 标签生成抽象成「冗余标签 + 阶段标记」的删除与 buffer 截断；
  论文**未给出**文本记忆的精确更新频率、记忆插入 prompt 的位置 / 顺序 / 模板、
  具体的压缩比。「失败不更新记忆」在探针里等价于删掉冗余，是一层抽象而非
  对 π_HL 更新规则的复现。
- D 组的「只文本对遮挡无效」来自世界里文本记忆不含抽屉位置信息这一设定；
  它对应论文「去视频记忆 → 不知已洗 / 擦多久、会卡住」的**机制方向**，不是
  对 Fig.5 消融柱高的复现。
