# pi-10：π0.7 的 diverse context conditioning 拆成可解析世界

对应文章：π 系列具身模型（10，系列收尾）π0.7（arXiv:2604.15483v2，
*π0.7: a Steerable Generalist Robotic Foundation Model with Emergent
Capabilities*，全文缓存 `10.html` / `10_v2.txt`，事实只取事实清单
`/tmp/pi_series_research/10_pi07.md`——**唯一允许的论文事实来源**）。

π0.7 不是新架构：作者明确「we do not aim to propose a new architecture」，
而是在 π0.6-MEM 一脉上把 prompt 从「只有一句任务语言」扩成**多模态、可引导的
上下文** 𝒞_t（总体任务语言 ℓ、子任务语言 ℓ̂、片段级元数据 m（speed/quality/
mistake）、控制模态标签 c、视觉子目标图像 g），训练时对每类分量随机 dropout，
测试时用 CFG 在 episode metadata 上「引导」模型，并用训练期 RTC 应对推理延迟。
本实验不重算真机成绩，只把「多分量 + dropout + CFG + 元数据 steering + 延迟」
这五件事各自的可解析后果钉死。

## 合成世界

**线性高斯条件模型**，纯 numpy / CPU / 固定 seed（20261110）/ 多 seed 平均
（40 seed；B 组 MC 2000 seed、自校验 400 seed）/ 每组末尾断言 / 最后打印总数。

`K=5` 个 prompt 分量各给一个标量上下文值 `x_k`（下标 0 任务语言、1 子任务、
2 片段元数据、3 控制模态、4 视觉子目标），`x~N(0,Σ)`，
`Σ=(1−ρ)I+ρ11ᵀ`（共享 latent 造成分量相关，这是 shortcut 的来源）。真值动作
在 `K` 个**正交 DCT-II 时间基** `U∈R^(H×K)` 上的系数
`z* = diag(B)·x + ξ`，`ξ~N(0,σ²I)`；轨迹 `a=Uz`。频率分配
`freq=[1,2,5,3,4]` 让元数据分量落在最高频基上（为 C 组高速档副作用埋构造真值）。

训练时按分量概率 `p_k` 把 `x̃=m⊙x` 喂给线性解码器 `W`；岭最小二乘的闭式解
`W* = R(M+λI)⁻¹`，`M=E[x̃x̃ᵀ]=DΣD+diag(p(1−p))`、`R=E[z*x̃ᵀ]=diag(B)ΣD`，
`D=diag(1−p)`。测试时给 prompt 的任意子集 `mask`，预测误差
`err(mask)=tr[(diag(B)−W*diag(mask))Σ(·)ᵀ]+Kσ²` 全闭式。`W*` 的非对角项就是
「用相关分量当另一个分量代理」的 shortcut。

自校验：Σ 正定、`UᵀU=I`、手写梯度 `∂L/∂W=2(WM−R)` ↔ 有限差分
（相对误差 3.75e-10）、`W*` 满足正规方程、闭式 `W*` ↔ 40 seed 有限样本拟合
（相对偏差 0.0016）、`cond_sample(w=0)` 高斯矩构造真值 ↔ MC 反算、
D 组 `s_soft=φ^d` 与 MC 反算增益一致。

## 反直觉结论（写正文须照此口径）

1. **A 组：缺了 dropout，模型并不特别忽略某个条件分量。** t=0 时五个分量
   遵从度完全相同（均 0.6240，岭正则均匀收缩）；真正被「忽略」的是**从没见过
   缺分量样本的无条件分支**（`err_uncond` 2.2919 最大）——这正是 CFG 负分支
   `C^uncond` 所依赖的东西。反过来，**dropout 概率越高，该分量的遵从度越低**
   （子目标图 0.6240→0.2371）：训练期让分量不可靠，模型就把容量集中到从不丢弃
   的任务语言与控制模态。代价是满上下文精度（`err_full` 0.6021→0.8596），
   收益是任意子集鲁棒性的 U 形最优点恰在论文 dropout 量级 t=1.0
   （`err_sub` 1.2439）。另有一个反直觉读数：**相对交叉项占比随 dropout 上升**
   （0.5036→1.2137），因为对角增益被压得比非对角更快。
2. **B 组：多样性惩罚把最优点从「纯遵从」向左推。** 纯遵从的解析最优
   β*=1.7027（有效增益 α 恰为 1），2000 seed 的 MC 实测最优 β_emp=1.75
   （差 0.0473，有限 seed 抖动），而含多样性惩罚的复合质量最优 β_Q=1.560。
   三者都落在论文 {1.3,1.7,2.2} 的中段附近，网格上 β=1.7 最好。
   κ / r / w_div 全为自设，这组绝对数值不构成对论文 β 取值的复现。
3. **C 组：可引导性最强的档副作用也最大。** 「快」档轨迹偏离最远
   （0.8750）、jerk 最高（0.1175）、跟踪误差（0.1134）与模型误差（1.0994）
   都最大；「标记失误」档不是最差档（误差 0.7827 介于稳与快之间）。
   元数据遵从度被 15% dropout 衰减到 0.5549——**训练期 dropout 直接削弱
   测试期 steerability**，这是 A / C 两组的同一枚硬币。
4. **D 组：条件化会放大延迟带来的分布偏移。** 只在 d=0 训练的条件化模型拿
   陈旧上下文当真值，误差从 0.4500 涨到 15.0813；**d≥9 步（180 ms）起
   反而比完全不条件化（10.6450）更差**。训练期模拟 0–12 步延迟后，
   `rtc` 误差 9.8318 始终不劣于无条件基线——收益来自学会按 `φ^d` 软化
   条件信任度，而非「条件越多越好」。

## 边界（本探针没建模什么）

- 世界是 **5 维线性高斯系数 + 24 步正交时间基**，不是 Gemma3 4B VLM +
  860M flow-matching action expert 的 transformer。block-causal attention
  mask、448×448 多相机、最多 3 张子目标图、由 BAGEL 初始化的 14B 世界模型、
  50 步 action chunk / 5 步去噪、FAST token / knowledge insulation 全部没建模。
- **离散文本本体状态属于 π0.6**；π0.7 跟随 MEM 用线性投影把 state 映射成
  token。本探针的「上下文分量」是 5 个标量，**不建模本体状态通路**，也不
  建立与 π0.5 / MEM 的表示对比。
- A 组把 dropout 映射成「分量以概率 `p_k` 置零」、把 prompt 子集映射成
  16 个 `(mask)`；论文的 25% 是「子目标图只加到 25% 样本」（present rate），
  30% 是「有子目标图时再丢子任务」，两者语义不同，本探针仅借用**量级**，
  不是对 §V-E 采样策略的逐条复现。控制模态在论文里不做 dropout（0%），
  探针里同样置 0。
- B 组把 CFG 退化成**两个高斯的 score 差**；论文只对 episode metadata 用 CFG、
  用 attention tree 打包正负样本，本探针不建模这些工程细节。`κ<1`（条件分支
  被 dropout 收缩）是为得到倒 U 而设的建模假设，不是论文声称的条件/无条件
  head 关系。
- C 组把三类元数据（speed 500 步离散 / quality 1–5 / mistake 布尔）抽象成
  **单个 steering 标量 `x₂`**，三档取值自设；不含文本字段、不含 quality=5 /
  mistake=false / speed 第 15 百分位的推理设定复现。
- D 组把延迟抽象成 AR(1) 上下文漂移下的**观测陈旧**，不是 06 篇的
  chunk 内 inpainting / 切换点 jerk；`soft_mask` 只用于验证「单调衰减、有界」
  这一共享性质，软化的是条件信任度。`0–12 步 / 240 ms` 是引用，探针里的
  `φ=0.90` 自设。
- 论文正文 / 112 条参考文献**零引用 RLT / RL Token**；RECAP 只在官方博客、
  论文实体是 π\*0.6。本实验不引入这些关系。
