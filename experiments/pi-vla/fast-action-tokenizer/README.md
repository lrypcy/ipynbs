# fast-action-tokenizer：FAST 的 DCT + BPE 到底省在哪

对应文章：[π 系列具身模型（02）：FAST —— 把动作块压成 token](https://lrypcy.github.io/2026/11/03/pi-vla-02-fast-action-tokenizer/)

## 要验证的论断

| 组 | 论断 |
| --- | --- |
| A1 | 分箱的 token 数**恒等于** `维度 × 步数`，控制频率翻倍就翻倍；FAST 在同一条物理轨迹上把采样加密 10 倍（H=5→50），token 数只涨 **2.03 倍**（21.1→42.9），压缩比从 1.66× 升到 **8.16×** |
| A2 | 固定 H=50、只改信号带宽：1 Hz → 33.1 token，4 Hz → 53.1 token（**0.62 倍**）。token 数跟**带宽**走，不跟采样率走 |
| B | `round(gamma*c)` 的归零阈值是精确的 $$1/(2\gamma)$$：所有非零系数都满足 $$\lvert c\rvert\ge 1/(2\gamma)$$；gamma 从 1 到 50，保留比例 6.4%→32.0%，RMSE 0.1033→0.0046；**gamma 越大越精细、token 越多** |
| B | 边际效率恶化 20 倍以上：从 gamma=1→2 每降 0.01 RMSE 只需多留 0.01 个百分点系数，gamma=20→50 要 0.23 个百分点 |
| C | BPE 的**独立**贡献是 1.24×–1.37×（拿掉 BPE 只留非零系数）；但 DCT 本身的功劳更大：14 维 50 Hz 下 700 → 112（非零）→ **83.5**（BPE），合计 8.4× |
| D | 同样 14 个系数：列优先最差维 RMSE **0.315**，行优先 **0.755**（2.4×）。行优先即使花到 224 个系数，最后一维仍是全零（0.727），因为它要等 650 个系数才轮到那一维 |
| D | 展平顺序还影响压缩：同一批系数，列优先 **83.0** token，行优先 **128.3** token |
| E | 达到 RMSE ≤ 0.02 所需 token：FAST **71.8**，分箱+降采样 **350**（4.9×）；64 token 预算下 FAST 0.0279、分箱 0.2082（7.5×） |
| E | FAST 的误差下限停在 0.0159（gamma=10 的量化噪声），分箱全分辨率 700 token 能到 0.0022 —— **分箱不是不能准，是要花 10 倍 token** |

## 运行

```bash
python3 fast_tokenizer_lab.py        # 全部 A–E，约 13 秒
```

环境：**纯 numpy**，无其他依赖。全部通过才输出 **断言总数 = 46**。

`fast_tokenizer_lab.ipynb` 是同一份代码的 notebook 版，输出已固化；`results/stdout.txt` 是
CPython 3.11.4 / numpy 2.1.1 下的完整输出，正文数字与它逐字对应。

## 四处关键设定

1. **合成数据是"同一条物理轨迹的疏密采样"**。每维一条 1 秒轨迹，由 3 个正弦分量
   叠加、带宽上限 `fmax` 可调，外加一个**直流偏置**（真实动作是绕着某个位姿摆动，
   不是零均值振荡）。H=5 和 H=50 采的是同一条曲线——不这么设，比较的就不是
   "编码同一段运动要多少符号"，而是"编码两段不同的运动"。

2. **BPE 词表压到 512、训练集只有 24–32 个 chunk**，目的是在 CPU 上十几秒跑完。
   所以这里的**绝对值不能和论文对表**（论文用 1024 词表 + 100 万条轨迹，7 维 50Hz
   的 chunk 只要 53 token，我这里 7 维 50Hz 是 43.6）。能对上的是**趋势**：
   分箱锁死、FAST 亚线性、列优先、BPE 有额外压缩。

3. **直流偏置决定 D 组结论**。第一版信号是零均值振荡，结果列优先/行优先的最差维
   误差只差 1.03 倍——因为"什么都不发"和"发一个均值"对零均值信号几乎一样好。
   加上偏置后，"把某一维整条丢掉"才真正变成灾难（0.755 vs 0.315）。这条差异
   本身值得记：**归一化方式会决定这类实验能不能看出差别**。

4. **gamma 的方向容易记反**。`round(gamma*c)` 里 gamma 越大，量化越细，
   非零系数越多、token 越多。第一版断言写成"gamma 越大保留越少"，直接失败。
