对应文章：[π 系列具身模型（01）：π0 —— 把 VLM 接上连续动作](https://lrypcy.github.io/2026/11/02/pi-vla-01-pi0-flow-matching/)

## 要验证的论断

| 组 | 论断 |
| --- | --- |
| A | 条件流匹配损失 $$L=\mathbb E\lVert v_\theta(x_t,o,t)-u\rVert^2$$ 的最优解是**边际速度场** $$v^*(x,t)=(x-\mathbb E[x_0\mid x_t=x])/t$$；用核回归独立复算，逐点偏差 < 0.026 |
| A | 端点行为：$$t\to1$$ 时 $$v^*(x,1)=x-\mathbb E[x_0]$$（去掉数据均值）；$$t\to0$$ 时在数据支撑点上 $$v^*\to-x_0$$ |
| B | Euler 是**一阶**方法：1→10 步误差降 9.68 倍，10→50 步仍降 4.22 倍 —— **10 步不是收敛点，是成本点** |
| B | **1 步 Euler 把整批样本塌成单点** $$x=\mathbb E[x_0]$$（残留标准差只有 $$t_{\rm lo}$$ 量级），模式归属错误率 **36.92%** |
| B | 10 步的模式归属错误率降到 1.33%，分布层面 W1 从 1.0193（1 步）降到 0.0173（50 步） |
| C | 时间采样 $$\mathrm{Beta}(1.5,1)$$ 的 $$\mathbb E[t]=0.6$$，偏向噪声端；换算成对均匀精度的重加权后 ESS/N = **0.7507**（要多采 1.33 倍样本） |
| C | 分区占比：数据端 $$t\in[0,0.2)$$ 只有均匀采样的 0.45 倍，噪声端 $$t\in[0.8,1]$$ 是 1.42 倍 |
| D | `make_attn_mask` 的 cumsum 技巧等价于三块结构：prefix 全双向 / state 单行 / action 全双向；可 attend 位置数 = 143（闭式核对） |
| E | KV cache 只重算后缀与全序列前向**逐位相同**（max\|diff\| = 0）；负对照（只打乱 prefix 的 V）偏差 1.472，证明测试有分辨力 |

## 三处关键设定

1. **时间方向按 openpi 源码，不按论文**。论文写 $$A_t^\tau=\tau A_t+(1-\tau)\epsilon$$（$$\tau=1$$ 是数据），
   openpi 写 `x_t = t * noise + (1 - t) * actions`（t=1 是噪声），源码注释原文是
   “yes, this is the opposite of the pi0 paper, and I'm sorry.”。两者等价但符号相反，
   本实验统一用 openpi 的方向，避免和正文公式打架。

2. **数据分布是合成的双分量高斯混合**，用来制造「同一观测下两种可行动作」的多模态。
   所有结论都是**合成探针**上的结论：它验证的是目标函数与积分器的数学性质，
   不是 π0 在真实任务上的精度。

3. **1 步塌缩不是数值巧合，是恒等式**。$$t=1$$ 时 $$v^*(x,1)=x-\mathbb E[x_0]$$，
   所以一步更新后 $$x=\epsilon-(\epsilon-\mathbb E[x_0])=\mathbb E[x_0]$$，
   与初始噪声无关。B 组把这条写成断言，而不是靠看图。

## 结论

- 训练目标本身没有近似：核回归（只用了 $$u=\epsilon-x_0$$ 的样本对）与解析边际场在
  $$t=0.2/0.5/0.8$$ 三个点上分别差 0.0139 / 0.0208 / 0.0259。差值是核回归的偏差与方差，
  不是目标写错了。
- 推理侧的精度**完全由步数决定**，且是一阶的。10 步的选择要跟「50 步还能再降 4.22 倍」
  一起看：省下的是 5 倍前向，付出的是约 0.117 的 RMS 误差（数据标准差 1.1338）。
- 少步数真正的危险不是幅度偏差，而是**模式选错**：1 步下 36.92% 的样本被并进多数模式，
  这类错误在闭环里会被下一帧纠正，在开环长动作里会直接做错事。
