# hi-robot：把开放式指令拆成子任务，拆了之后换来什么

对应文章：π 系列具身模型（04）Hi Robot（arXiv 2502.19417）。

Hi Robot 的全部操作可以写成一句话：**在 π0 前面再挂一个 VLM，让它把开放式指令和插话
先变成一条原子命令，π0 只消费这条命令**。这句话里有四个容易被略过的细节，本实验就是把它们钉死：

1. **分层换来的是「把监督信号拆成离散分类 + 连续回归两步」**，不是「组合泛化」。
   在合成探针里，把（约束, 技能）格子挖掉之后两边都泛化不了；真正稳定的差距是数据效率。
2. **重算周期是设计参数**，最优值等于一个原子技能的持续时间。
   比它更频繁会被**两边支配**（步数更多、高层调用也更多）；比它更稀疏是用时间换算力。
3. **接口是文本，所以有脆弱处**：高层说出的措辞必须落在低层训练时见过的命令上，
   偏离一点动作误差就涨，而且这个退化可以靠低层的标签扰动增强缓解。
4. **合成标注只喂高层**，不喂低层——因为它补的是「什么样的用户语句会引出这一步」，
   而低层缺的是动作原型，两件事的数据是分开的。

**只验机制，不重算论文成绩**：三个平台的 IA / TP、GPT-4o 对照、专家上限都是引用。

## 合成世界

桌上有 5 个物体，每个 4 位二值属性（±1）。用户指令是一个**作用在属性位上的筛选谓词**：
把「满足谓词的、还没处理的」物体逐个收走。谓词写成 (require-1 位, require-0 位)，
编码成 4×3 的逐位 one-hot——**每个属性位是一个独立输入槽**，组合结构从这里来。

- 训练约束：8 个「单位谓词」（只约束一个位）
- 测试约束：4 个「两位合取」的复合谓词（多从句指令的替身）
- 6 个技能（5 个真技能 + 一个 done），每个技能是一个 8 维动作原型 μ_s
- 真值动作 a\* = μ_{s\*} + Bx + η；η 是不可预测噪声，给出动作误差下界 0.155

## 边界

- 世界里的「技能」是 8 维动作原型，「约束」是 4 个属性位上的谓词，规模比真机小好几个数量级。
- 高层 / 低层都是两层 MLP（隐藏 64），不是 PaliGemma-3B。**论文那个「VLM 的网页预训练先验
  在语言空间里更好用」的论证，这里测不出来**——本实验只测「拆成两步」这一半。
- B 组的「命令一变就重新起一段」是建模假设，不是 π0 的实测行为。
- C 组用「one-hot 加一个固定方向的扰动」代替真正的同义改写，只量**偏离程度**这一个变量。
