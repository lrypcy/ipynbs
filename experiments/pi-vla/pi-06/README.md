# pi-06：延迟下动作块怎么接，RTC 的 inpainting 到底补了什么

对应文章：π 系列具身模型（06）RTC（arXiv 2506.07339v2，*Real-Time Execution of Action Chunking Flow Policies*）。

π0 / π0.5 这类 flow-based VLA 一次输出一个长度为 $$H$$ 的动作块，只执行前 $$s$$ 步就换下一个块。
但生成一个块要花 $$\delta$$ 时间，折成 controller timesteps 就是
$$d=\lfloor\delta/\Delta t\rfloor$$。同步执行要停下来等，朴素异步不等却在切换点把机器人
扔到分布外。RTC 的答案是不重训练、不改训练配方，**只在推理时把新 chunk 当成一张被挖掉一部分的图来补**：
前 $$d$$ 个动作已经过去，冻结到已知值；中间与上一 chunk 重叠的部分按 Eq.(5) 的软掩码做
guidance；末 $$s$$ 个动作超出上一 chunk，让模型全新生成。

本实验把这套机制拆成四组可解析的对照，**只验机制，不重算论文成绩**。

## 合成世界

真实 flow policy 的 ΠGDM guidance 在**线性高斯流**里退化成「带权重观测的高斯后验」，有闭式解，
因此不必真的跑 5 步去噪就能扫很多 seed：

- 动作轨迹是周期平滑函数 `profile(mode)`，$$m\in\{+1,-1\}$$ 表示两种相反的策略模式
  （绕障碍上方 / 下方）。两个模式逐点平均会互相抵消——这正是 temporal ensembling 的失效来源。
- 旧 chunk 走 $$m=+1$$；按 Alg.1 取 `A_prev = A_cur[s..H−1]` 右填充成目标 $$Y$$。
- 新 chunk 在 $$d$$ 步前的观测上生成，先验相位滞后 $$d$$；观测越陈旧，策略模式分叉概率越高
  （$$p_{\rm flip}=\min(0.5,\,0.03d)$$）。这是「延迟 → 分布偏移」的显式建模。
- 方法对照：`naive`（不看旧 chunk）、`hard`（只冻结前 $$d$$ 个）、`exp`（Eq.5 指数衰减）、
  `linear`（线性衰减，附录 A.4）、`te`（两个相反模式的预测逐点平均）、`sync`（每次都拿到当前观测）。
- 指标：切换点附近 7 个点的**最大二阶离散差分**（论文附录 A.2 用最大加速度作 OOD 代理）、
  新段平均动作幅值（动作是否有效）、重叠区 RMSE、成功率（加速度 < 0.42 且幅值 > 0.30）。

常量与论文 §4.2 / Table 4 对齐：$$H=50$$、$$s=25$$、$$\Delta t=20$$ ms、$$n=5$$、$$\beta=5$$；
$$d\in\{0,6,11,16\}$$ 对应无注入 / 基线 / +100 ms / +200 ms 注入。

`series_common.py` 在上一级目录，提供 `Check`（断言收集）、`soft_mask`、`ar_kernel`、
`cond_sample`、`jerk`、`mean_std`。06–10 五篇共用，不要修改它。

## 四组实验

| 组 | 对应论文 | 钉死什么 |
| --- | --- | --- |
| **A** | Eq.(5)、Eq.(2)–(4)、附录 A.2 | 软掩码三段式（前 $$d$$ 权重 1／中间单调指数衰减／末 $$s$$ 权重 0）；指数 ≤ 线性；`d > H−s` 时退化成 hard；$$n=5$$ 的 guidance 权重序列 `[5.0, 4.25, 2.1667, 2.1667, 4.25]`，$$\tau=0.2$$ 的 4.25 就是「$$\beta\ge4.25$$ 时裁剪只作用于第一步」的出处；闭式后验在 $$W=0$$ 时严格退化成先验 |
| **B** | Fig.2 / Fig.4 / Fig.5 / Fig.6 | 延迟下 naive、hard、soft、TE、sync 的切换点加速度、动作幅值、成功率与 throughput |
| **C** | 附录 A.2 / Fig.7 | 把 ΠGDM 的 VJP 近似成单位算子后，第一步收缩系数 $$\text{gain}=1-(k+\beta)/n$$；$$\lvert\text{gain}\rvert>1$$ 即单步超调发散，解释为什么 $$\beta=5$$ 是 $$n=5$$ 下唯一不超调的设定、而 $$n=100$$ 时 $$\beta=150$$ 也不发散 |

## 关键读数（逐位对齐 `results/stdout.txt`）

- **掩码**：$$d=11,s=25,H=50$$ 时中间 14 个权重从 `0.8381` 降到 `0.0027`，指数和 `3.8792`、线性和 `7.0000`。
- **B 组切换点加速度**：`d=0` 时 naive `0.2592`、soft `0.2002`；`d=6` 时 naive `0.9149`、soft `0.2127`；
  `d=16` 时 naive `0.6425`、soft `0.1966`。soft 在四档延迟上落在 `0.1838–0.2002`，几乎不动。
- **成功率**：soft `1.000 / 0.988 / 0.988 / 0.988`（$$d=0/6/11/16$$），naive `0.938 / 0.000 / 0.438 / 0.487`。
- **TE**：chunk 内加速度 `0.2118`（$$d=11$$）低于 naive `0.3099`，但幅值从 soft 的 `0.5647` 塌到 `0.0870`，
  成功率四档全 `0.000`——「降加速度但产生差动作」。
- **C 组**：$$n=5$$ 时 $$\lvert\text{gain}\rvert$$ 依次 `0.10 / 3.10 / 9.10 / 29.10`（$$\beta=5/20/50/150$$），
  首步最大加速度 `0.2647 / 1.3172 / 3.6284 / 11.3321`；$$n=100$$、$$\beta=150$$ 时 $$\lvert\text{gain}\rvert=0.5050$$。
- **D 组**：sync throughput `0.9375 → 0.5716`，RTC `1.0000 → 0.9875`；
  $$d=16$$ 的比值 `0.6098` 恰好是 $$s/(s+d)=25/41$$。
  换 mode 时与理想块的 RMSE：naive `0.1564`、hard `0.3925`、soft `1.1159`。

## 必须诚实说明的边界

1. **不是复现真机 / Kinetix 成绩。** 论文 480 episodes / 28 小时、12 个 Kinetix 任务、6 个真机双臂任务、
   2048 rollouts、76 ms / 97 ms、`20% faster`、`2.3×`、`2.5×` 全部只是引用。
   **Fig.5 / Fig.6 的曲线没有数值表**（只有 95% Wilson 区间与 ±1 SEM），不能目测估数充当精确事实。
2. **线性高斯流不是 flow matching。** `cond_sample` 是 ΠGDM guidance 在可解析情形下的闭式对应物，
   用来比较「同一测量口径下各方法的相对差异」；C 组另用离散迭代演示单步超调，把 VJP 近似成单位算子。
   两者都不是论文 Alg.1 的真实网络实现。
3. **合成世界的「陈旧观测」是显式建模**：相位滞后 $$d$$ 与 $$p_{\rm flip}\propto d$$ 是自设的，
   不是论文里的物理量；它们只负责让「延迟 → OOD」在探针里可见。
4. **几条反直觉结论不要抹掉**：
   - TE 的 chunk 内加速度确实低，但**切换点**加速度并不低（`d=11` 时 `0.6865`）——幅值塌掉会造成另一类不连续；
   - soft 对注入延迟鲁棒，但当新观测**要求**换策略模式时，guidance 会把合法切换一起压回去
     （RMSE `1.1159` vs naive `0.1564`），这是「让新 chunk 纳入新观测」与「保持策略连贯」之间的真实张力；
   - naive 的加速度在 $$d=6$$ 达峰 `0.9149` 后回落，不是单调上升；端点比较 `0.2592 → 0.6425` 才显著。
5. **许可证**：RTC 是 CC BY 4.0，官方图可以引用；但本系列 01–10 统一**自画**，不复用论文截图。
   图 1–3 是按 §2–§3 / Alg.1 / 附录 A.2 的文字重画的结构图，图 4–7 的数字全部来自本实验 stdout。
