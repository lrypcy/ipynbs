# knowledge-insulation：断在哪两个矩阵上，断了之后 α 还是不是旋钮

对应文章：π 系列具身模型（03）KI（arXiv 2505.23705）。

KI 的全部操作可以写进一个公式里：**action expert 读 backbone 的 K / V 时加 stop-gradient**。
这句话里有两个容易被略过的细节，本实验就是把它们钉死：

1. **只断两个矩阵** $$K_b, V_b$$，不是四个。$$Q_b$$ 和输出投影不用管——它们本来就拿不到
   流匹配的梯度（掩码决定了 backbone 行读不到 action token）。
2. **断了之后 α 就不是旋钮了**。流匹配损失与离散动作损失作用在**互不相交**的两组权重上，
   相对权重不会影响 backbone 的轨迹（实测：α ∈ {1, 8, 32} 三跑参数**逐位相同**）。

**只验机制，不重算论文成绩**：LIBERO / DROID 表、7.5 倍步数、收敛速度都是引用。

## 五处关键设定（都是踩出来的）

1. **语言标签不能依赖物体名字**。第一版标签是 $$\arg\max(\text{NAME}[c] P_{gt}^\top)$$，
   而回答位自带 `NAME[c]`，等于答案写在查询里——打乱图像 token 后准确率只掉到 **0.600**。
   改成只依赖**当次扰动** $$\epsilon_c$$ 后，打乱掉到 **0.268**（随机水平 0.25），
   负对照才成立。

2. **动作必须依赖整幅场景，不能只依赖被选中的那一个**。expert 的 query 只来自带噪动作
   与时间，不含指令，注意力只能摊在 4 个物体上；若动作只依赖 $$\epsilon_c$$，信号会被另外
   3 个物体的独立噪声稀释 4 倍。实测后果：六种配方的动作误差全卡在 0.52（与下界 0.515 一致），
   指标彻底失去分辨力。

3. **流匹配的噪声 ω 要与动作块 A 同协方差**。这是最要紧的一处。$$x_t = τA + (1-τ)ω$$
   里本来就带着 $$A$$ 的信息，expert 不读 backbone 也能反解出一部分 $$u$$。
   $$\operatorname{cov}(u,x_t) = (1-τ)\Sigma_ω - τ\Sigma_A$$，令 $$\Sigma_ω = \Sigma_A$$
   在 τ=0.5 处严格为 0；$$A$$ 与 $$ω$$ 都是高斯，不相关即独立。第一版用标准高斯噪声时，
   `freeze` 与 `ki` 的动作误差是 0.428 / 0.429 —— 完全分不开。

4. **动作块里要有「不可预测」的那部分**。$$A$$ 若严格低秩（秩 3 / 35 维），秩之外的方向上
   $$A\equiv 0$$，那些方向的 $$u$$ 可以直接从 $$x_t$$ 反解。加上 20% 方差的不可预测噪声
   （对应真实机器人「同一场景两次示范也不一样」）并归一化后 $$\operatorname{Var}(A_d)=1$$，
   捷径被完全堵死。

5. **$$P_{gt}$$ 与 `NAME` 取正交行**。随机高斯行会让 4 个类别的 argmax 区域互相纠缠，连
   「在精确特征上跑多项 logistic」都只能到 0.85（实测），语言任务的天花板被标签几何卡住；
   正交行把天花板抬到 0.97。另外 $$U$$（动作读数）投影到 $$P_{gt}$$ 的正交补后**必须重新
   正交化**，否则 $$\operatorname{Cov}(s)\neq\sigma_s^2 I$$，$$\Sigma_A$$ 就配不准。

## 一处必须说明的不一致

论文说 KI「收敛更快」（π0 需要 7.5 倍步数），本玩具**没有复现，方向是反的**：
同样步数下 naive 的探针 R² 0.730 vs ki_vlm 0.326，动作误差 0.424 vs 0.479；
把 ki_vlm 训到 9000 步（3 倍）也只到 R² 0.281 / act 0.484，追不上。

原因是玩具 backbone 只有 32 维、K/V 瓶颈秩 8，从零重新学会动作表示只要一千步，
「流匹配梯度毁掉预训练知识」的代价在这里几乎不存在——而真实 3B VLM 的代价正是论文
那条结论的来源。所以 D 组的最后一条断言写的是「代价」，不是「更快」，
正文也会照实说。
