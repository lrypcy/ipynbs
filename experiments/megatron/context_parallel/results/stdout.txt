[§4] 三条路线的 KV 通信量（解析模型）
  口径：单层、全序列长度 S、单元素 BYTES 字节；只算 K 与 V 两个张量。
  p2p(ring)：每 rank 自持 S/cp，逐步收到其余 cp-1 段 → 每 rank 收 (cp-1)/cp·S
  all_gather(THD)：每 rank 一次性拿到全序列 KV → 每 rank 收 S
  a2a(Ulysses)：头按 CP 组切，a2a 后每 rank 持全序列但只有 1/cp 的头
           → 每 rank 收 (1/cp)·S 个「头份额」，全网合计与 ring 相同
      cp       p2p 每rank      all_gather 每rank       a2a 每rank        AG/p2p
       2            2.00                  4.00            2.00      2.000000
       4            3.00                  4.00            1.00      1.333333
       8            3.50                  4.00            0.50      1.142857
      16            3.75                  4.00            0.25      1.066667

[§4] 全网合计 KV 字节（每 token 折算，S=1）
  p2p(ring) 合计 = cp × (cp-1)/cp·S = (cp-1)·S → 随 cp 线性增长
  all_gather 合计 = cp × S → 随 cp 线性增长，系数比 ring 大
  a2a(Ulysses) 合计 = S → 与 cp 无关，每个 KV 元素只过一次网络
